# 下蹲、蹲拳与扫腿

正式运行素材为三名角色各一张独立蹲姿、一张独立蹲拳（`*-crouch.png`、`*-low_hit.png`），以及 `sweep-atlas.png` 中三个扫腿姿态。全部由内置 image_gen 生成，原图未切割、抠图或重采样。

`single-prompts.json`、`sweep-generation.json` 保存实际提示词、生成源图、尺寸、透明通道范围与 SHA-256。蹲姿和蹲拳实际透明范围 0–255；运行时通过 `duel-crouch.ts` 使用统一脚底锚点。扫腿按单独检查的 viewport 显示。

`atlas.png` 是早期六姿态候选，人物在单元格边缘靠得过近，会带入邻帧残片，因此已停用，保留来源记录 `generation.json`。它的透明通道有效，带色 RGB 预览不能代表合成后存在背景。

操作：S 下蹲；S＋J 蹲拳；S＋K 挑空；N 站踢；S＋N 扫堂腿；空中 N 飞踢。P2 用方向下＋数字1/2，腿键为主键盘句号或小键盘小数点。蹲防与蹲拳、扫腿统一使用低位受击高度；挑空在有效攻击帧恢复站立高度。
