# 连续动作组

三张原生 RGBA 图集，每张四列六行，共 72 个帧位。由内置 image_gen 基于各自角色参考生成。实际提示词、源图与哈希见 [motion-prompts.json](../../motion-prompts.json)，运行裁显区域见 [motion-geometry.json](../../motion-geometry.json)。

每行四帧依次为：跑动循环、第一拳、第二拳、踢击、挑空、受击/跌落/倒地/起身。运行时由 `motion-frame.ts` 按真实动作的起手、有效攻击和收招阶段选帧；倒地时按是否落地和剩余硬直选择跌落、躺地或起身。

图集不保证每个人物都严格位于等分格子内，因此根据可见人物范围检查每一帧的 SVG viewport，保持同一角色的统一缩放和身体横向枢轴。PNG 像素没有修改，不把平移同一张图计作额外帧。原生图片的透明通道为 0–254，正确使用 alpha 合成后背景透明。

动态预览见 [motion-preview.html](../../motion-preview.html)。当前每组四帧，仍可继续扩充过渡帧、独立特殊技和更多动作分支；本批已经用于实际战斗。
