# 战斗关键姿态与独立特效

本批目标：DeepSeek、豆包各 12 张关键姿态，另有 6 张独立特效，共 30 张透明 PNG。使用内置 image_gen，每张单独生成。完整实际提示词、参考图、生成来源与文件对应关系保存在 [combat-prompts.json](../combat-prompts.json)。

这些图已经接入游戏：按实际动作与出招阶段切换关键姿态，并统一脚底锚点和站立高度。GPT 另补十二姿态图集，参见 [gpt/README.md](gpt/README.md)。当前以关键姿态切换呈现动作，完整连续动画仍需补中间帧。

## 角色与镜头锁定

- DeepSeek：蓝色渐变长发、鲸鳍耳、鲸尾、白色女仆头饰、蓝白女仆服、深蓝靴；保留脸颊米粒。
- 豆包：深棕侧分齐下巴短发、露额头、红围巾、深色卫衣、黑短裤与深色打底裤、黑红运动鞋；禁止双丸子头、齐刘海、橙色服装、白上衣。
- 右朝向，固定正交侧面略带四分之三角度；生成时请求统一人物尺寸、上方与四周留白、地面脚底位置。
- 第一张参考图锁定身份，第二张战斗待机图锁定战斗造型。生成所得实际画幅、透明边界会另行检查；提示词中的位置是生成目标，不冒充精确的实测锚点。
- 角色层禁止夹带攻击弧光、气泡、火花、地面、阴影、文字和其他人物。独立特效另图提供。

## 提示词使用方式

JSON 中每项 `prompt` 是可直接使用的完整提示词，`references` 按顺序传入图片。要重做一个动作，只调整末尾的姿态描述，不删除身份和镜头约束。改变发色、服装、镜头或整体比例属于新版本，应另存文件。

后续补中间帧时，每个动作以本批起手/命中关键姿态为参考，逐张生成：预备 → 蓄势 → 出招 → 命中 → 跟随 → 收招。每一步只改变明确的手臂、腿部、躯干角度，并在专门的锚点校准环节检查缩放和抖动。不要用整张大招图代替身体动作，也不要把同一姿态平移当作新动作帧。

## 质量核对

逐图查看身份、朝向、四肢、裁切和道具。检查 PNG 能否解码、真实透明通道、尺寸、非透明边界、SHA-256。保留生成原图，不以代码抠图、修肢体、重采样或拼接补救生成问题。

素材预览见 [combat-preview.html](../combat-preview.html)，实际动作可在游戏练招房体验。碰撞判定与动作时序仍由游戏规则控制，位图大小不会改变攻击范围。
