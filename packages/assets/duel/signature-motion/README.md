# 招牌动作图集

当前包含 DeepSeek 的八帧白饭动作：

1. 端出饭碗
2. 蹲下护饭
3. 夹起白饭
4. 大口塞饭
5. 鼓腮咀嚼
6. 吞咽满足
7. 举空碗结算
8. 收碗回到架势

运行校准：

```sh
python scripts/calibrate-duel-advanced-motion.py --family signature-motion
```

校准只读取PNG的透明通道，生成 `geometry.json` 和 `manifest.json`。不会裁切、缩放或覆盖原始图片。

豆包同目录包含八帧回旋气泡演出：

1. 查看退回气泡
2. 蓄力准备甩锅
3. 气泡离手
4. 空手随挥
5. 装作与自己无关
6. 发现气泡返回
7. 护脸等待重拳拒收
8. 尴尬恢复架势

甲方包含八帧不可拆指令投：

1. 递出合同
2. 指着签字位置
3. 伸手锁人并举章
4. 合同贴身强制签署
5. 抬起返工对象
6. 红章伤害结算
7. 压向地面
8. 举合同收势

提示词仙人包含两组各四帧动作：

- U飞符：抽符、敲键盘、发符、掌势收招。
- F符阵：蹲下画阵、落符、结印启动、抱臂收势。

断网大爷包含两组各四帧动作：

- U拉线：拿插排、甩网线、网口命中、后仰拉人。
- F断网：检查插头、蹲下抓线、拔线命中、离线拳架。
