# 战斗吧，大肥鱼：新角色素材第一批

## 当前运行版本：每人 48 帧

`motion/` 新增九张正式动作图集，共144帧，已替换游戏中的六姿态基础表现。查看 `motion/preview.html`，或从本页旧素材预览进入新版。

每人包含三张图集，各16帧：

- mobility：跑动；起跳/上升/下落/落地；下蹲/蹲防/蹲拳/扫腿；受击/腾空/躺地/起身。
- ground：轻拳、重击、站立踢、招牌技，各四阶段。
- aerial：挑空、空中踢、投技各四阶段；两个待机与两个防御姿态。

实际成品为1254×1254透明RGBA，格子间距并非严格等宽；必须使用 `motion/geometry.json` 的逐帧viewport，不能直接按四等分切图。原图未经裁切或重采样。`motion/manifest.json` 保存正式版本与SHA-256，`motion/prompts.json` 保存内置image_gen提示词，`motion/repair-record.json` 保存甲方印章防裁切、大爷跑动节拍的返修来源。原六姿态素材保留为加载失败时的后备。

以下为首批素材记录。

使用内置 image_gen 制作，三套正式 RGBA PNG 图集，共 18 个动作关键姿态。

| 角色          | 正式素材                    | 核心道具                   |
| ------------- | --------------------------- | -------------------------- |
| 甲方·再改一版 | `client-poses-v2.png`       | 修改意见、巨型拳头、红印章 |
| 提示词仙人    | `prompt_sage-poses-v2.png`  | 键盘、黄拖鞋、提示词符纸   |
| 断网大爷      | `unplug_uncle-poses-v2.png` | 插排、网线、花裤衩         |

每张 1536×1024，3 列 × 2 行，每格 512×512。按行顺序：待机、拳击、腿法、防御、受击、招牌技。角色面朝右，反向可镜像显示。PNG 原始 alpha 已保留，未重新采样或程序抠图。`manifest.json` 保存逐格源坐标、可见边界、透明比例及 SHA-256。

用 `preview.html` 查看 18 个独立姿态，可切换深色、浅色、棋盘背景与左右朝向。图集的 RGB 预览可能显示彩色底纹，正常 alpha 合成时背景透明。

`prompts.json` 保存初版提示词，`production-prompts.json` 保存完整生成与留白修订提示词、来源路径。v1 为留档草稿，部分姿态越过格子边界；正式使用 v2。v2 已检查每格边缘，未出现相邻姿态侵入。

首批通过 `packages/assets/src/duel-newcomers.ts` 接入六人游戏阵容，当前已由上面的48帧动作组替代主要显示。提示词仙人的符阵为减速机制，不会将对手角色图片变成鸡；甲方支持摔投，但未制作双角色抓取专用动画。
