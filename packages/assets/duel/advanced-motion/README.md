# 六角色进阶动作图集

2026-09-28 使用内置 `image_gen` 生成并接入游戏。

- **6张运行图集，96帧**：每人16帧，4行×4列。
- 第1行：闪避翻滚（压低、团身、倒立翻转、低姿起身）。
- 第2行：站立击飞（蓄力、出脚、送出、收腿）。
- 第3行：防御反击（挡住、回拉、顶回、收手）。
- 第4行：空中击飞（蜷腿、出脚、伸展、收腿）。

甲方用文件夹顶回、仙人用键盘挡推、大爷用插排反击；三个看板娘保持已有角色形象，豆包仍为棕色短发、黑衣和红围巾。仙人初稿出现重复键盘，`prompt_sage-v2.png`已修正，v1仅留作记录。

## 文件与接入

- 逐帧预览：`preview.html`，支持角色/动作选择、播放、单步、镜像和深浅底色。
- 生成提示词：`prompts.md`。
- 生成来源记录：`generation-record.json`。
- 版本、哈希与尺寸：`manifest.json`。
- 显示裁切和锚点：`geometry.json`。
- 资源导出：`packages/assets/src/duel-advanced-motion.ts`。
- 运行渲染：`games/duel/src/AdvancedMotionSprite.vue`，由`RasterFighter.vue`选择；`advanced-frame.ts`按实际招式时序选帧。

`roll / blowback / guardCounter / airBlowback`使用专用素材。后撤翻滚按位移方向镜像，普通攻击仍按面向对手的方向播放。减少动态效果时，闪避使用起手/恢复两帧。加载失败回退到原动作，避免角色消失。

## 非破坏性校准

原始PNG像素和透明通道未经修改。`scripts/calibrate-duel-advanced-motion.py`只读取透明轮廓并输出JSON：

- 以实际连通轮廓确定视口，避免机械等分切断伸出的腿或道具。
- 每个角色只使用一个缩放比例，避免把下蹲/翻滚放大成站姿高度。
- 地面拳脚按脚底区域定位，翻滚与空中动作按动作底部锚定。
- GPT与豆包有两处相邻行靠得很近，显示边界避免采样邻帧；最多裁掉共享外缘1个源像素（游戏中不足半像素），原图保持完整。

浏览器已逐人检查全部96帧能播放，验证后撤镜像、图片失败回退、减少动态效果和预览窄屏布局。实际截图见工作区`.cache/advanced-*-*.png`。本批不包括独立轻脚、EX、高阶超必杀或双方抓取动画，它们仍需后续补齐。
