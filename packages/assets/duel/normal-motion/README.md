# 轻脚与空中拳图集

六张透明PNG，每名角色16帧，共96帧，已接入游戏：

| 图集行 | 实际动作                         | 按键  |
| ------ | -------------------------------- | ----- |
| 1      | 站立轻脚：准备、抬膝、低踢、收腿 | M     |
| 2      | 蹲轻脚：蹲稳、伸腿、点踢、收腿   | S＋M  |
| 3      | 空中轻拳：护脸、伸拳、直拳、收拳 | 跳＋J |
| 4      | 空中重拳：蓄力、下挥、重砸、收拳 | 跳＋K |

空中M仍用快速踢的已有动作；空中N改用`advanced-motion`里已有的向下重踢动作，四种空中拳脚不再全部共用飞踢图。地面N保持原重脚/扫堂腿。

## 制作与显示

内置`image_gen`逐人生成，角色身份以已有素材为参考，豆包保持侧分短发、红围巾、黑衣。原PNG的像素与透明通道未经后期修改。共同提示词和身份约束见`prompts.md`，工具输出映射见`generation-record.json`。

`geometry.json`按真实透明轮廓裁切，每个角色使用同一个比例：站姿参考高度142逻辑单位，蹲姿不放大。各帧锚点对齐角色位置，空中拳的脚保持蜷起。

校准命令：

```powershell
python scripts/calibrate-duel-advanced-motion.py --family normal-motion
```

运行时由`normal-frame.ts`选择帧，通过共用的`AdvancedMotionSprite.vue`显示。前两格在前摇内播放；第三格的完整拳脚伸展从实际命中帧开始；第四格用于收招。单张素材加载失败只回退该角色的普通拳脚，不影响独立翻滚/防反图集。

## 预览与验证

`preview.html`提供六角色、四组动作、播放/暂停、单步、镜像与深浅底色。

- 浏览器真实按键逐人读取全部96帧，核对空中拳、轻脚和重脚的图集选择。
- P2手机按钮与镜像、图片请求失败回退、预览窄屏布局通过。
- 七项专项检查确认各角色命中帧显示完整伸展、恢复帧正确，以及所有裁切范围有效。
- 原PNG与生图工具输出字节一致；透明度、视口和邻帧串图检查通过。

EX、角色招牌技、高阶大招、双方抓取的专用动画仍有剩余工作；本批主要解决基础拳脚复用造成的辨识问题。
