# 消消乐素材包

这里登记本次导入的 60 张独立 RGBA PNG。原始压缩包还包含 16 张源图集和概念参考图，
但源图集没有复制到运行资源目录，避免未经必要引用的原图进入构建范围。

素材状态为 `generated-pending-review`：

- 包内说明将素材标记为本次对话生成的同人风格素材。
- 包内没有品牌、角色或第三方素材授权证明。
- 角色名称只用于主题分组，不表示官方形象、官方认证或合作关系。
- 本目录可供消消乐开发和本地原型使用，尚未作为公开发布素材完成审核。

`asset-manifest.json` 保留每张图的 ID、分类、尺寸、来源图集记录和 SHA-256；
`asset-list.csv` 方便人工核对。`@moecore/assets/match3` 提供 Vite 构建可用的资源 URL。

`tiles` 下的 `*_tile_portrait` 和 `*_tile_symbol` 是同一组六类棋子的两套皮肤，
不能默认当作十二类棋子。`effects` 是静态纹理，不包含动画序列；
`powerups` 和 `obstacles` 只代表图像资源，不代表对应规则已经实现。
