## 运行图

`runtime/` 是 `scripts/prepare-whale-assets.py` 从上述 PNG 生成的无损 WebP 缩小图，
保留比例、整理透明边距，并为角色统一显示画布与底线。源 PNG 字节没有修改。
运行图清单同时记录输出和来源哈希，不复制完整生成提示词到浏览器。

`bg_far` 与 `keyart_menu` 原图为 RGB，另外 70 张为 RGBA；“72 张”不代表全部透明。
源动画锚点只是提示词目标，本次对齐仍是原型级处理，不能取代逐帧美术精修。
