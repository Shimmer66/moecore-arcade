# 鲸鲸的灵感长队素材

本目录收录自 `D:/A-Work/贪吃鱼素材/Whale_Queue_Assets_75` 的核心 P0/P1 素材，供
`@moecore/game-whale-queue` 的开发与公开试玩原型使用，首页还复用一张角色图。公开试玩范围按项目所有者已确认的决定执行，详见[总素材清单](../CREDITS.md)。素材属于候选生成稿，仍需按原素材包中的
`QA_zh.md` 完成最终美术与发布许可审核。

当前游戏使用简洁 CSS 棋盘外框，保留的 `backgrounds/frame_board_outer.png` 未被当前组件引用。玩法说明见[鲸鲸的灵感长队](../../../docs/games/whale-queue.md)。
