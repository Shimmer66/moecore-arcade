# 别乱生成！完整玩法重构

## 用户目标与当前差距

用户要求完整复刻上述参考游戏 Level Devil 的玩法，结合 AI 特点和 meme，所需素材使用 GPT Image 生成，游戏要有趣。目标持续有效；当前三关收星与限次撤销不构成完成。

2026-09-28 检查：当前运行入口仍是 `games/arena/src/ArenaGame.vue`，三关，每关三颗必收星，撤销临时关闭唯一事故。只有第一批角色和浮岛场景素材。上一轮属于有实际修改和验证的进展，但没有完成用户目标。

## 参考依据

以开发者 Unept 的 [Steam 页面](https://store.steampowered.com/app/3242750/Level_Devil/)为可靠来源。页面列有约 240 个关卡、单人、同机双人竞速、玩家可触发陷阱干扰对手以及秘密内容。核心体验是看似简单的到门目标、会变化的场景、对玩家预期的连续反转、失败后立即再试。

此前使用的 `playleveldevil.com` 并未独立证实属于开发者，后续引用以 Unept 商店页面与实际游戏观察为准。

## 实施方向

- 以抵达出口为统一目标，星星改为可选秘密挑战。取消撤销关闭困难的主循环。
- 左右移动、跳跃、短关卡、快速死亡与重生；每次失败保留玩家对机关的认知，机关行为可重复学习。
- 机关覆盖：触发地洞、突然尖刺、落块、追踪或巡逻锯、移动出口、移动平台、反向控制、反重力、假出口、连环触发、限时通道、回程反转。
- AI 机制与笑点绑定：幻觉桥、自信假出口、上下文删除地面、过度优化反向控制、思维链变成实体落块、限流闸门、自动补全延伸尖刺、用户追问触发二次陷阱。
- 内容按章节递进：首次识别、变式、组合、反预判、章节挑战。先制作 40 个可独立验证的主线关卡，再按机制覆盖与实际节奏审查缺口；数量本身不能作为完成证据。
- 同机双人竞速共用同一套物理与关卡，提供可以影响对手的机关。补充章节选择、本地进度、最佳用时、死亡统计、秘密收集及重玩。
- GPT Image 制作背景、机关物件与角色动作/表情；使用当前蓝发鲸娘作为形象基础。用户已明确授权素材生成，无需再次确认。

1. 机制和关卡模型：进行中。纯规则引擎与显式触发器；碰撞、重生、入口出口、平台运动及事件时序可复现。
2. 关卡内容：待开始。章节逐步引入机制，各关存在真实可执行路线；秘密路线也需验证。不能靠传送、改状态或跳过碰撞证明通关。

4. 双人模式和进度：待开始。独立玩家输入/失败、竞速胜负、机关互相影响、持久化和重玩。
5. 美术：进行中。机房背景已提交内置 GPT Image 生成；保存原稿、提示词、校验值与运行文件，逐项接入并检查真实画面。
6. 综合试玩：待开始。正常输入覆盖全部关卡和模式，桌面/触屏，视觉截图，难度与节奏审计。修复任何不可通行、纯等待、反应窗口不足、机关不明确或重复填充关卡。

## 完成证据

最终核对原始目标：机制覆盖、完整游玩循环、AI 梗在机制中成立、GPT Image 素材实际显示、全部内容正常可达、同机双人可玩、进度可恢复、桌面和触屏可操作。测试通过只能证明其覆盖的行为；趣味性需要逐关观察惊喜、读懂原因、重试成本、选择与组合，不能以单次脚本跑通声称已经有趣。

当前目标保持 active，不以本计划、素材生成或一个可玩章节标记完成。
