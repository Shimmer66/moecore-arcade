# 模型战争：模型战争

用户完整目标：模仿魂斗罗玩法，完整复刻并超越其游戏体验，同时融合 AI meme，可用 GPT Image 生成素材。实现以原创关卡、美术和音乐承载完整动作玩法，不把“八关能运行”当作目标完成。保留游戏 ID、宿主契约与角色形象。

## 执行单元

1. 已实现基础规则：固定步长、八关、普通/硬核、六种武器、手雷、敌人预警、八 Boss、有限续关和计分；完整战役平衡尚待验证。
2. 已实现基础呈现：键盘/多点触屏、角色素材、生成背景和 Boss 图集、短音效、命中反馈、HUD。
3. 已接入宿主暂停/重开/结算及独立演练；持续验证受影响行为。
4. 已实现纵向关卡：第三关记忆塔、缓存复活、顶层守关战；正常伤害下实际输入完成全段攀升。
5. 已实现本地双人合作：独立输入/生命/装备、共享世界、协作镜头、借命重连、共同进场与结算；全战役体验仍由最终验收覆盖。
6. 已实现第二/第六关纵深基地、五条独立横向路线、运输平台/传送带、42个角色动作单元、手动武器库和独立增益栏。
7. 已通过普通/硬核 × 单人/双人的八关规则回放与桌面/手机完整浏览器重放。原版说明书对照已记录在 `docs/games/rewrite-fidelity-audit.md`；补给链路、独立增益、平台下落、基地推进/能源屏障与组合弱点守关均已有实现。旋转火球也已补齐。剩余包括关卡顺序/难度边界、巢穴与最终核心递进、持续运行和最终验收。

## 约束与事实

- 工作区有大量既有未提交更改；仅修改本游戏相关文件，不回退或覆盖其他游戏工作。
- 改造前原型长度 34 单位、前三类敌人、仅末关 Boss；不保留已被新设计替换的旧规则测试断言。
- 用户已授权实现及生成素材；没有 Git 提交、推送或发布请求。
- “超越”是设计目标，不能由自动测试证明；报告可验证的交付与真人手感限制。
