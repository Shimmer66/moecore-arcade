# AI 梗动作跑酷实施计划

## 目标与范围

2026-09-28 用户访谈已解除原作范围歧义：用户明确“可以借鉴多款游戏的特点”，期望一局约三分钟、普通玩家约三次尝试通关，并授权自行设计失败重试。当前执行目标为一段融合多款特点的原创连续冒险，不再以四款商业原作全内容逐项复制为验收标准。

本轮已实现：四段连续流程“干饭取件 → 算力飞跃 → 节拍核验 → 最后交付”，正常路线目标 160～195 秒。各段入口为检查点，失败重试当前段，已完成段的得分保留且失败分数不累计；一次失败后提供公开标注的阶段援助。主入口为连续冒险，现有单项保留为练习。约三次通关是调难目标，不把自动回放当作真人成功率证明。

本轮验收：673 项规则测试、类型、lint 和生产构建通过；52 项组合浏览器检查全部通过，后续准备页与窄屏补测通过。两端完整冒险覆盖四段自动切换、交接时暂停、统一结算、整局重开和不污染练习纪录，正常回放约 183 秒；失败场景验证第二段检查点、已完成成绩保留、失败分数不累计和明确援助。已检查完整结算、检查点界面、320×640 运行画面及准备页；修正了窄屏标题孤字换行。证据位于 `.cache/parkour-journey-final`、`.cache/parkour-journey-layout`、`.cache/parkour-journey-ready`。当前可玩版本已完成上述功能交付，真人约三次通关的体感仍需实际试玩校准。

用户要求将当前大肥鱼跑酷做成完整、有挑战、有趣、融合 AI meme 的游戏，参照饼干跑酷的收集与动作循环、雷曼的关卡编排、Jetpack Joyride 的爆发与无限模式、Muse Dash 的角色与动作反馈。采用原创角色素材与关卡表达；新增位图需要时使用 GPT Image。不是只改文案或提高速度。现有工作区含大量未提交改动，在现状上迭代，保留其他游戏。
