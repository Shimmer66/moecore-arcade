# 摸鱼局 UI 规范

本规范用于首页、游戏宿主及游戏外围控件。当前实现以 `apps/web/src/styles.css`、`App.vue`、`HomeView.vue`、`games/GameHost.vue` 为准；游戏场景由各游戏组件管理。

## 品牌与视觉方向

展示名为“摸鱼局”，页面标题为“摸鱼局 · AI 小游戏俱乐部”。仓库目录、`@moecore/*` 包名、游戏 ID 和存储命名空间沿用既有标识，修改展示名不要求迁移它们。

页面使用白底、冷灰辅助区域和蓝色主操作。通过排版、间距和浅色表面区分层次，避免连续嵌套描边卡片、厚阴影及无实际含义的装饰标签。游戏角色、棋盘和场景可保留独立美术；玩法内危险、奖励等状态色不受品牌蓝限制。

## 共享变量

变量在全局 `:root` 定义，游戏组件通过 CSS 继承，不跨包导入应用源码。

| 变量               | 当前值    | 用途               |
| ------------------ | --------- | ------------------ |
| `--ui-bg`          | `#fff`    | 页面背景           |
| `--ui-surface`     | `#fff`    | 浮层表面           |
| `--ui-subtle`      | `#f5f7fb` | 次级区域、操作栏   |
| `--ui-ink`         | `#182230` | 标题与正文         |
| `--ui-muted`       | `#667085` | 辅助说明           |
| `--ui-line`        | `#e9edf3` | 分隔线             |
| `--ui-accent`      | `#4169e1` | 主按钮、选中与强调 |
| `--ui-accent-soft` | `#eef3ff` | 浅色操作背景       |
| `--ui-radius`      | `16px`    | 通用面板圆角       |

`--home-bg`、`--home-ink`、`--home-muted`、`--home-line`、`--home-purple` 是既有游戏的兼容别名，其中 `--home-purple` 现已映射品牌蓝。新增样式使用 `--ui-*`，维护旧组件时逐步替换别名。

游戏特有颜色放在本游戏作用域内。不要为调整游戏场景重写全局按钮或正文样式。

## 字体与密度

使用系统无衬线字体栈，包括 Segoe UI Variable、Segoe UI、Microsoft YaHei UI 等；当前未加载外部字体。页面基础字号为 14px，行高 1.6。

首页主标题为 34–48px，游戏库标题为 20–22px；游戏工具栏标题为 16–18px，桌面卡片标题为 16px、手机为 14px。中文标题避免夸张字距。

主内容最大宽度为 1184px。桌面使用较大的两侧留白，手机通常保留 16px 边距；间距优先使用 8、12、16、24、32px。辅助文字应保证小屏可读；现有部分 9–11px 浅色标签仍待复核，不能将其作为新增正文的推荐字号。

## 页面与组件

- **导航**：Logo 作为首页入口，站内链接与外部 GitHub 链接分开表达。游戏页面复用站点外壳，手机游玩时收起顶部导航。
- **游戏库**：桌面三列，中等视口两列，极窄屏一列。分类按钮使用 `aria-pressed` 表达状态；整张游戏卡是可聚焦的开始入口。
- **封面**：角色图从 `@moecore/assets` 的公开映射读取，在素材清单中登记复用。缺图时显示通用图标；AI 娘闯关使用 DeepSeek 娘射击姿态。
- **主操作**：使用 `.primary-button` 或 `.home-button-primary`，蓝底白字，最小高度 44px、圆角 9px。
- **辅助操作**：使用 `.text-button` 或 `.icon-button`；图标按钮必须有可访问名称，不能只依赖 hover 提示。现有图标按钮为 36–40px，新增触屏主要操作优先提供至少 44px 点击区域。
- **暂停与结算**：由 `GameHost.vue` 统一渲染 `.overlay-panel`，背景适度模糊，内容强调当前状态和下一步操作。
- **重开与退出确认**：宿主使用原生 `dialog`，明确说明对局不会保留，提供继续与确认操作。
- **游戏场景**：棋盘、规则反馈和角色动作由各游戏控制。鲸鲸棋盘使用简洁 CSS 外框；跑酷与 AI 娘闯关保留独立场景画面。

新增游戏应复用外围控件和变量，避免复制完整宿主。封面配置与注册表目前分开维护，新增游戏需同时检查两处。

## 响应式与交互验收

全局主要断点为 960px、700px 和 360px；游戏可针对棋盘结构使用局部断点。检查 1440px 桌面、390px 手机和 320px 窄屏，确认无横向溢出、标题不遮挡操作、关键按钮可点击。

鲸鲸手机布局将开始按钮与方向键置于棋盘后、说明文字前。其他游戏也应优先让操作靠近玩法画面，而不是让玩家滚过说明后才能控制。

新增交互必须支持键盘与可见焦点；弹窗打开时应将焦点移入，关闭后恢复到合理位置。动态效果应尊重系统减少动态效果设置及宿主传入的 `settings.reduceMotion`，主要操作不应只在 hover 时出现。

## 当前缺口

以下是待修要求，并非已完成的验收结论：

1. Logo 与顶部站内导航尚未接入宿主离局确认。
2. 暂停、结算面板尚未完整管理键盘焦点的进入与恢复。
3. 部分辅助标签的字号与对比度需复核。
4. 首页关键路径与鲸鲸玩法尚缺专用持续浏览器回归；真机、完整通关与所有浏览器兼容性未完成验收。

测试命令与证据边界见[开发指南](development.md)，待办状态见[路线图](roadmap.md)。
