# 推演对决：抽象搞怪素材方案

状态：首批 12 张静态样张已生成并完成透明通道和预览检查，见[素材目录与预览说明](../../packages/assets/duel/README.md)。本页其余道具拆层、动作与音频仍为后续制作方案。

## 1. 要做出的感觉

角色平时可爱，出手时短暂帅到离谱，失手后一秒破功。重点是“角色把 AI 的话当真了”：蒸馏真的拿蒸锅，生成真的像打印机吐纸，省字真的把一长串废话压成拳头。

画风采用粗线条的 Q 版漫画，约 2.5–3 头身；表情和手势夸张，主轮廓清楚，色块数量少。专业梗负责第二层含义，蒸锅、纸张、包子等实物负责让路人直接看懂。

同一角色保留稳定的头发、衣服和主要轮廓；“脸突然画崩”“脑袋突然放大”只发生在受击贴图和大招插片。正常移动与攻击保持统一比例，玩家始终能判断角色在哪里。

## 2. 三人各自的视觉笑点

| 角色        | 平时的形象                                                         | 帅的瞬间                                                   | 破功的瞬间                                           | 不能丢的识别点                 |
| ----------- | ------------------------------------------------------------------ | ---------------------------------------------------------- | ---------------------------------------------------- | ------------------------------ |
| DeepSeek 娘 | 蓝发鲸鱼娘，尾巴拖地，表情像刚睡醒但硬说自己在思考                 | 慢慢抬眼，加载圈变成金色准星，锅盖飞起，小拳头带蒸汽冲出来 | 眼神失焦、头顶冒烟，思维线绕成毛线团；被摔后还在转圈 | 蓝发、鲸尾、蓝白服装、思考状态 |
| GPT 娘      | 白发小龙娘，薄荷绿点缀，抱着比自己还厚的“最终版”草稿               | 三拳对应三版稿子，最后双手举巨型印章砸下                   | 笑容僵住，偷偷把第一版塞回去；白龙角挂满改稿便签     | 白发、龙角、薄荷绿、纸张和印章 |
| 豆包娘      | 深棕侧分短 bob、露额头、红围巾和深色上衣；基准亲和，表情变体再搞怪 | 大气泡被压成一个字，突然变成鼓鼓的大包子拳套               | 嘴角一滴口水、慢半拍才察觉气泡瘪了，围巾也垂下来     | 侧分露额、红围巾、深色上衣     |

最重要的表情对比：**“我稳了”与“我装的”**。每人都需要自信、懵住和嘴硬三种情绪，不能只换一张微笑头像。

豆包以用户直接提供的头像为身份依据，取消双丸子头、齐刘海、白上衣和橙色盘扣装。参考、区别及修正版约束见[豆包形象核对](../../packages/assets/duel/doubao-reference.md)。包子继续作为技能道具。

## 4. 第一阶段接入：六组可复用道具

样张确定风格后制作透明部件。以下是六组创意单元，不等于六个最终文件；锅盖、纸张等需要分层才能运动。

| 道具组   | 必要部件                                 | 怎样动才好笑                                               | 对应已实现行为                                  |
| -------- | ---------------------------------------- | ---------------------------------------------------------- | ----------------------------------------------- |
| 蒸馏小锅 | 锅身、锅盖、蒸汽、迷你拳套               | 锅盖先抖两下，拳套像刚蒸好的馒头弹出，锅身还留在原地冒烟   | DeepSeek 成功反击；同一命中事件，不新增追击伤害 |
| 小鲸专家 | 一个专家身体参考、两种脸、独立大锤与椅子 | 两只专家从椅子上慌忙蹦起来，一只帽子掉了，仍拼命保持专业   | DeepSeek 大招特写                               |
| 无限改稿 | 空白纸、揉皱纸、折角便签、纸团           | 先有条不紊地叠三张，最后一张像喷纸机失控；失败时倒着收回去 | GPT 三连 / 灵感连击的视觉反馈                   |
| 发送印章 | 章柄、章底、空白印面、压下尘圈           | 印章巨大，角色被带着砸下，印完还拔不出来一小下             | GPT 大招特写                                    |
| 嘴硬气泡 | 饱满、鼓胀、命中破裂、漏气四种状态       | 发出时昂首挺胸，命中“啵”地炸；飞出场时像气球放屁般瘪掉     | 豆包唯一在场投射物；可见轮廓贴近半径 22 的判定  |
| 豆包拳套 | 包子本体、捏褶、夸张拳头轮廓、蒸汽尾迹   | 废话气泡越压越小，拳头越变越大，最后只剩一个大字           | 豆包大招特写                                    |

技能名、草稿版本、印章内容和大字由程序叠加，方便切换台词、字号与左右朝向。不要把“已发送”“揍”等关键中文永久画进位图。

## 5. 三个大招的素材分镜

| 时段         | DeepSeek：专家会诊                 | GPT：综上所述                          | 豆包：省字不省拳                             |
| ------------ | ---------------------------------- | -------------------------------------- | -------------------------------------------- |
| 0–0.25 秒    | 一排椅子亮灯，只有两只鲸反应过来   | 第一版、第二版稿子快速翻过             | 长气泡从嘴边挤出来，小人仍在自信解释         |
| 0.25–0.75 秒 | 两只专家举锤扑来，主角淡定指向对手 | “最终版”纸张炸开，巨章举起             | 气泡被双手压缩，小小的“揍”字鼓成包子拳套     |
| 0.75–1.2 秒  | 双锤汇成鲸鱼轮廓，定格“这题我会”   | 章砸下，定格“已发送”；角色脚还悬在空中 | 大拳套把对手和画面边框一起撞歪，定格“包办了” |

这些镜头只在已经确认命中后出现，伤害仍按当前规则一次结算。无需额外制作完整视频，透明部件的缩放、位移、短暂定格就能表达这个过程。

## 6. 战斗动作素材：第二阶段

第一阶段用新表情、道具和特写增强当前 SVG 身体，保持现有完整操作。之后再替换全身动作，避免为了十二张插画让站立变漂亮、出拳仍像换头像。

每个角色的动作必须覆盖：待机、前后移动、冲刺、起跳/腾空/落地、蹲下、轻击三段、站重/蹲重/空中攻击、防御/格挡、投技/被抓/拆投、受击、倒地/起身、技能、大招起手、胜利和失败。

攻击至少分出蓄势、接触、收招三个关键姿态。DeepSeek 尾巴慢半拍，GPT 纸张慢半拍，豆包气泡慢半拍，这些“跟不上主人的道具”负责喜剧节奏；真正的拳头必须跟得上命中时间。

不要求图片生成工具直接生成一整张精确动画图集。先拿统一角色参考制作关键姿态，再用部件动画或人工对齐补间；导出时核对脚底、头身比例和朝向。最终图集从这些已检查的帧打包。

## 7. 共用表情、场景和音频

**共用视觉件**：粗线命中星、格挡透明锅盖形光弧、受击扁脸轮廓、飞走的一粒“灵魂小白豆”、胜利大拇指、尴尬汗滴、空白弹幕牌。都应很短暂；“小白豆”只是 KO 喜剧演出，不代表新资源。

**场景补强**：把现有“服务器机房大舞台”做成机房里临时搭的擂台。远景机柜安静亮灯，中景是抱饭碗的小鲸观众，角落电风扇拼命吹一个过热机柜；前景只有不影响判定的胶带和舞台边缘。观众在 KO 时统一举错牌，立刻慌忙翻面。背景少动，战斗时保持低对比。

首期场景只需远景、观众层、地面边缘三个独立层，不需要大量地图。

| 音效     | 建议质感                   | 用途                     |
| -------- | -------------------------- | ------------------------ |
| 轻击     | 短促纸板“啪”               | 基础三连，三段略变调     |
| 重击     | 塑料盆“咣”加低频重音       | 让土味声音也有打击重量   |
| 格挡     | 锅盖“叮”                   | 明确告诉玩家挡住了       |
| 反击     | 微波炉完成提示加弹簧声     | DeepSeek“蒸好了”         |
| 投技     | 橡皮拉伸加坐垫闷响         | 抓起与落地两个触点       |
| 气泡     | “啵”与漏气“噗”             | 命中与飞出场的反差       |
| 大招落点 | 盖章闷响 / 双锤 / 蒸汽爆发 | 各角色共享时序，声音不同 |
| KO       | 短锣声接一拍安静           | 留出字幕笑点             |

配音首批建议 12 句：每人开场、成功、破功各一句，共 9 句，再加开打、KO、平局 3 句。自己录制或合成新录音即可；用普通话和夸张语气建立反差。比如 DeepSeek“想完了”/“没算到这步”，GPT“再来一版”/“刚才不算”，豆包“包的”/“这次没包住”。常规短句以约 0.5–1 秒为目标，长句留给选角和结算，不拖慢招式。

## 8. 文件交付与验收

- 角色基准建议 1024 × 1024 透明底；半身表情同尺寸，脸占画面约三分之二。它们是高分辨率母版，运行尺寸另行导出。
- 道具建议 512 × 512 或 1024 × 1024 透明底；长纸条另用宽画布。留足锤子、尾巴、蒸汽的边缘空间，不裁切。
- 大招演出样稿为 16:9；接入版另拆主体、道具、背景和特效层。没有背景的精灵仍导出真实透明通道。
- 角色动作统一面朝右、脚底锚点一致；左侧通过程序镜像。文字与朝向独立处理。装饰不得扩大受击区；超大拳套只在命中后的特写中自由夸张。
- 运行时按用途压缩和缩小，按当前游戏加载；具体体积以实际导出和手机检查为准，不把 1024px 母版逐帧直接塞进每帧动画。
- 逐项记录来源、母版、运行文件与对应角色/事件。仍保留当前 SVG 回退，确保某张图加载失败不会中断战斗。
- 在真实显示尺寸检查：手机角色约几十像素高时仍能认出头发、角/尾巴/红围巾；表情贴图放大后不过度遮挡血条和动作预兆。
- 验收同时看无字预览、成功/失败成对预览、深浅背景透明边缘、大招 1.2 秒分镜、减少动效状态。好笑程度需要试玩观察，不能由文件数量或生成成功判定。

**制作顺序：12 张风格与笑点样张 → 六组可动画道具 → 角色全身关键姿态 → 场景与音频 → 后续四角色。** 最先验证 DeepSeek 蒸锅、GPT 巨章、豆包漏气这三个视觉包袱。
