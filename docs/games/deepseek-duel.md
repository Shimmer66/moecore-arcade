## 一句话体验

玩家操纵 DeepSeek 娘，在短局对战中观察对手、寻找破绽，用普通攻击确认命中、用推演技能反击，积攒能量打出终结演出。胜利来自读招和操作，不来自真实 AI 模型能力的比较。

## 核心支柱

1. **上手快**：移动、跳跃、轻击、重击、防御、技能构成基础操作。新玩家不用记复杂指令也能完成攻防。
2. **有对抗**：普通攻击可衔接短连招；防御能挡正面攻击，近身投技可破解持续防御，失误有明确硬直。
3. **角色有差异**：每名角色有不同的距离偏好和招牌技能，但共享移动、受击、资源和胜负规则。
4. **短局可重玩**：单局约 2–4 分钟，失败后能马上再战；角色台词只点缀战斗，不打断操作。

### 角色性格、笑点与演出

下面的梗是虚构角色的舞台表现。对白不暗示真实产品会这样回答，也不把任何真实模型的能力当作角色强弱依据。

**DeepSeek 娘｜“等我想完，你就完了”**

- **推演刺**：剑尖先出现一条细细的蓝色思路线，下一拍才刺出。中距离出手清楚，空挥后容易被贴近。
- **推演架势**：头顶亮起“正在思考…”，周围冒出一堆看似高深的箭头；接到正面攻击时箭头突然全部倒指对手，角色说“这步我算到了”。它是短窗口反击，不能一直举着等。
- **答案回溯**：往后退半步，把刚才的动作残影留在原地延迟出刀。笑点是残影还在疯狂补充推理，实际攻击只发生一次。
- **答案收束**：满屏公式先像要写论文，瞬间折成一把光刃，屏幕只剩“最终答案：你倒了”。须近距离起手命中才进演出，空放会浪费能量。

**GPT 娘｜“不满意？那我再来一版”**

- **灵感上挑**：把一张写着“初稿”的纸从地上挑起，连人一起打飞；适合近身衔接，打不到远处目标。
- **灵感连击**：每一下都像现场重写招式，残影依次贴着“第 1 版”“第 2 版”；最后一击突然改成“最终版”。是贴身突进，整套被防住会暴露破绽。
- **即兴改写**：把一次普通攻击的收招动作“删除”，立即换方向再打一击；需消耗能量，不能无限取消。
- **无限联想**：命中后画面快速切成几种荒诞画风，连击结束盖章“先这样，下一版更强”。起手距离短，不能从全屏无代价发动。

**Claude 娘｜“我会温柔地请你退场”**

- **边界推掌**：双手推出发光边框，击退对手，不擅长连续追击。
- **边界结界**：举起写着“安全距离”的透明牌，挡住一次正面打击后把对手推开；对投技无效。成功时温柔地说“我们保持一点距离”。
- **温和驳回**：用一封巨大但措辞非常礼貌的“退回说明”把对手推走；能打断贴身压迫，但出手慢。
- **守护协议**：结界化成一整页条款，最后只保留一句“建议你先躺下休息”。属于防守反击型终结技，对手不打过来就难以触发完整演出。

**Gemini 娘｜“我们两个都觉得这招行”**

- **双轨踢**：地面是上挑，空中是斜踢；两条星轨同时在画面留下短暂轨迹，让对手能看清来向。
- **双视角**：地面招向上截击，空中招斜下俯冲；画面像同时开了两个窗口。选择错角度时有明显落地或收招空当。
- **星轨跃迁**：借一道星轨移动到半空，不会瞬移到对手身后，落点可预判。
- **星轨交汇**：两道残影从上下包抄，碰撞后合成一颗夸张的小星星，字幕“达成共识”。对手可在起手时闪开或防住。

**Kimi 娘｜“等一下，我前文还没翻完”**

- **卷轴横扫**：拖出一条长得离谱的卷轴，边打边展开“前情提要”；攻击范围长，但收卷时无法立刻防御。
- **长卷展开**：卷轴沿地面延伸，最后一页写着“重点在这里”；对手可以跳过，近身时不安全。
- **段落回环**：已飞出的卷轴突然回收，补一次延迟打击；卷轴去程和回程都有清晰轨迹。
- **万页归一**：数百页“补充说明”飞满背景，忽然压缩成一页，把对手拍飞，字幕“摘要完毕”。前摇较长，适合惩罚远处的大动作。

**GLM 娘｜“别动，我先把你排进表格”**

- **格点踏步**：脚下浮出方格，按格点滑步并短打，擅长调整站位。
- **结构重排**：把地面临时画成表格，对手踩入某格会短暂减速；格线预先亮起，可跳过或绕开。
- **逻辑锁定**：把已放置的格点连成一对发光括号后引爆。没有格点就按不出来，布阵需要时间。
- **逻辑矩阵**：全场升起巨型表格，几列依次闪烁再爆发，最后一列的标题是“结论：挨打”。它是可读的范围技，不瞬间覆盖整个场地。

**豆包娘｜“这事儿，包在我身上”**

- **接话击**：先递来一个可爱的对话气泡，下一拍气泡变成拳套；两段节奏直观，适合新手确认命中。
- **对话气泡**：发射一个圆滚滚的气泡，撞上对手时弹出“收到！”；飞行慢、可防可跳，用来逼对手移动。
- **话题跳转**：借弹跳气泡向前冲，上勾拳把对手送上天；没打中会在空中停一下，给对手反击机会。
- **热聊时刻**：先用近身一击启动，彩色气泡排队追着对手，最后变成一只巨大豆包“啪”地盖章；演出结束角色还认真补一句“还有什么可以帮你？”

幽默主要放在台词、字幕和命中后的短演出里。攻击范围、前摇、防御反馈必须在笑点出现前就能看懂；终结技特写统一 1.2 秒，开战前可选择简短镜头，战斗暂停时长一致。

## 对局流程

选角色与对手 → 进入场景 → 最多三回合对战 → 结算 → 再战或返回游戏库。

- 每回合 75 秒，先让对手生命归零者获胜；时间结束按剩余生命比例判定，完全相同则该回合平局。
- 先赢两回合者获胜；平局占用回合但不加胜场。三回合后比较胜场，多者获胜，相等则整场平局。
- 双方基础生命、移动速度、受击规则相同；角色差异主要体现在攻击范围、节奏和技能。
- 无随机暴击、装备、抽卡、体力或跨游戏养成。

| 移动 | 左右移动、跳跃、蹲下；角色自动面向对手，不能穿过对方             |
| 攻击 | 轻击起手快，重击范围或击退更强；确认命中后可接有限的短连招       |
| 防御 | 按住防御可挡正面攻击；防御中不能攻击。近身投技克制持续防御       |
| 技能 | 每名角色一个招牌技能，有明确前摇和冷却；失手后可被反击           |
| 能量 | 命中与有效防御积累少量能量；满槽可发动一次终结技，演出简短且可读 |
| 受击 | 有短暂硬直、击退和倒地保护；同一连段伤害递减，避免无限连         |

终结技是战斗奖励，不应在残血时保证逆转。详细规格已给出命中范围、时序和伤害的初值，需在可玩原型中调试。

### 操作方案

- **键盘**：A/D 移动，W 跳跃，S 蹲下，J 轻击，K 重击，L 防御，U 技能，O 投技，I 终结技；双击左右冲刺。完整输入与容错见详细规格。
- **触屏**：左侧方向、跳跃和蹲下，右侧轻击、重击、防御、技能，另有独立投技与大招按钮；无需同时按两个攻击键。首版触屏以人机对战为目标。
- 宿主暂停、失焦暂停、重开和结算沿用现有游戏接入协议；暂停时清除持续按键，恢复后不能自动出招。

## 模式与首版范围

| 阶段       | 交付范围                                                                                        | 验证问题                                     |
| ---------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------- |
| 战斗切片   | DeepSeek 娘镜像对战、几何占位、移动/攻击/防御/受击/胜负                                         | 走位、命中反馈和攻防是否好玩                 |

首版人机提供一个默认难度：会接近、攻击、防御和偶尔使用技能，但不读取玩家未来输入，也不做不可反应的完美防守。本地双人留到键位、设备和对局平衡确认后加入。

## 美术与声音方向

- 角色采用与摸鱼局一致的原创 Q 版像素或手绘精灵风格，优先保证站立、移动、轻重攻击、防御、受击和倒地的动作辨识度。
- 场景以“草稿空间”为主题，背景动效弱于战斗角色；用清楚的命中闪光、停顿和音效表现打击，不用大面积遮挡画面。
- 角色名和技能名可以使用 AI 主题梗，界面操作提示保持直接。所有声音都能关闭，减少动态效果设置应降低非必要的镜头震动与闪光。
- 新增图片与音效在制作时登记到素材清单。角色形象与名称的发布审核沿用项目现有状态管理。

## 工程边界与验收

游戏以新的 `games/*` 包接入现有 Vue 宿主；规则层保持纯 TypeScript。可参考现有横版游戏的输入和场景经验，但格斗的帧状态、碰撞盒、连招和胜负应由本游戏独立实现。首版离线运行，不调用大模型 API。

可玩版至少验证：攻击与防御优先级、双方同时命中、边界碰撞、投技、防止无限连、计时平局、暂停恢复、触屏多指输入、重开后无残留动作，以及完整三回合的人机对战。真人试玩重点观察“是否看得清招式”“失败原因是否明确”“想不想立刻再战”。

## 待定的产品决定

- 美术风格在像素精灵与手绘精灵之间选择；两者的动画制作方式和资源量不同。
- 本地双人是否需要进入首版；本草案建议先把人机对战手感做扎实。
