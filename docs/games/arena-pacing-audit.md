# 关卡节奏检查

检查方法：所有45关分别尝试一直向右、落地即跳、每40帧跳一次；
每条路线最多1200帧。另以既有正常输入秘密路线记录完成时间。
这是定位漏洞的探针，不代表真人难度或趣味性评分。

## 确认的问题

三个回程关中，移动出口扫过玩家会直接触发成功。
这使一直向右也能通过，既有通关测试虽为绿色，却没有证明回程机关被实际游玩。

| 房间           | 修复前秘密路线耗时 | 修复后 | 修复后的三种盲操作 |
| -------------- | ------------------ | ------ | ------------------ |
| 百分之百确定   | 3.9s               | 6.3s   | 均未通关           |
| 已回滚到上一版 | 3.8s               | 6.0s   | 均未通关           |
| 自主规划中     | 3.9s               | 7.0s   | 均未通关           |

修复：单次移动的出口在停稳之前不接受通关；运行中降低不透明度并显示交叉标记。
仍允许玩家站在最终目的地等待门停稳。这是可行的路线判断，不额外禁止。
循环移动出口仍保持可进入，用于工坊的不同玩法。

新增 `return-route.test.ts` 同时证明：

- 一直向右不会被移动门扫过而获胜。
- 正确路线到达远端后向左走超过100帧。
- 回程机关确实触发，最终在左侧出口成功并保留秘密。

## 保留的简单关

“向上发展”是首次介绍反重力，直走可通过；“别想太多”用不必要跳跃触发危险，
故步行是设计中的正确解法。未因盲操作可过而机械增加危险物。

剩余重点：持续连跳可通过若干入门或动作关，需结合章节位置判断；
当前样本不证明所有时序具有合理反应余量，也不消除参考内容未逐关对应的差距。

## 连续评测长关补验

“最后还差亿点点”的秘密路线会触发全部七组机关。
逐次取消第一地洞、尖刺、巡逻锯、假门、末尾地洞的对应跳跃，会在对应危险物处失败；
取消闸门前等待会撞闸门。这证明这些操作对路线有实际作用。

初次围绕既有回放起跳点测试正负三帧，假门的晚三帧失败。
进一步扫描每次起跳前后十帧后，每个跳跃都存在至少七个连续可通关起跳帧。
既有回放的假门起跳点处在窗口后段；没有为迎合测试改动地形或碰撞。
这只证明独立调整一次跳跃时的时间窗口，不是同时扰动所有输入的难度认证。
