# 稳稳接住你 · 承诺实验室

入口：`/#/games/steady`，独立包：`@moecore/game-steady`。

当前版本包含五关救援挑战与自由实验。玩家摆放道具、试跑、观察失败轨迹，再调整布置；物理规则决定结果，关卡不会根据“用了某套道具”直接播放成功动画。

## 五关与逐步解锁

| 关卡           | 必须完成的目标                     | 可用道具                                 | 预算 |
| -------------- | ---------------------------------- | ---------------------------------------- | ---- |
| 先借你一张床   | 将用户送到地面接应点               | 蹦床 1                                   | 2    |
| 锅替你赶路     | 磁力参与用户的地面救援             | 锅 1、磁铁 1                             | 4    |
| 你怎么往上掉   | 气球参与救援，抵达天花板           | 锅 1、气球 2、磁铁 1                     | 6    |
| 画的饼该放下了 | 借气球与右向穿堂风移动，剪绳后落地 | 蹦床 1、气球 2                           | 3    |
| 这两口锅也归你 | 接住用户和两口指定的锅             | 蹦床 2、气球 2、磁铁 1；两口锅为固定起点 | 7    |

预算消耗：蹦床 2 点、磁铁 3 点、锅 1 点、气球 1 点。数量上限与预算同时生效；第五关的指定锅不占玩家预算，也不能在布置阶段移动或删除，可以给它们绑气球。

第一关从一开始可玩，通过后解锁下一关。自由整活一直可进入，保留原有的全套道具和地面/天花板切换。

第四关的风是持续向右的加速度，对未接住的用户和锅均生效；上方箭头展示方向。剪绳保留惯性，不能只看竖直落点。

## 星级和进度

成功获得基础一星。另两颗星对应界面明确列出的“自放道具数量”与“临场调整次数”要求。剪断气球、磁铁断电或重新通电计一次调整；慢放、暂停不计。

| 关卡           | 道具数量星              | 调整次数星  |
| -------------- | ----------------------- | ----------- |
| 先借你一张床   | 不超过 1 件             | 0 次        |
| 锅替你赶路     | 不超过 2 件             | 0 次        |
| 你怎么往上掉   | 不超过 3 件             | 0 次        |
| 画的饼该放下了 | 不超过 1 件             | 不超过 1 次 |
| 这两口锅也归你 | 不超过 2 件，不含指定锅 | 0 次        |

本地最多累计 15 星。保存各关最好星数、最快模拟时长和最少道具数，这三个最佳值可来自不同尝试。刷新后优先进入未完成关卡，其次进入尚未满星的关卡，全部满星后进入自由实验。

存储键为 `moecore:game:steady:v1:campaign`。读入时校验已知关卡、星数、有限时长与道具数；异常数据被忽略。写入失败时提示进度只保留在当前游玩中，不阻止继续游戏。

同次访问中切关会暂存各关布置；刷新仅恢复成绩，不恢复道具布局。

## 操作循环

1. 选择道具后点击房间放置；“放到建议位置”提供起点，不保证通关。
2. 拖动道具、旋转蹦床、撤销修改，准备好后点击“放手，看看”。
3. 模拟时可剪断全部气球绳、切换磁铁通电状态、半速观察或提前停下。
4. 失败后保留原布置和上次路径，方便针对一个问题调整。
5. 成功后可以继续优化星级、进入下一关，或查看宿主结算。

一次模拟最长 14 秒。没有要求玩家在编辑阶段限时完成布置。

键盘：道具聚焦后，方向键微调，Q/E 旋转，Delete 移除。指定锅不会响应移动和删除。触摸取消或宿主暂停会撤销尚未完成的拖动，不把半次操作留在布局里。

## 物理与因果

- 锅放在用户头上会成为金属头盔并增加质量；其他位置形成独立金属物体。
- 磁铁只吸金属物体，穿锅头盔的用户会随之移动。
- 气球必须绑在人或独立锅上；浮力按所绑对象质量计算。
- 蹦床按倾斜角度反射速度，并提供弹力。
- 剪绳停止浮力，断电停止磁力，原有速度继续保留。
- 用户、锅互相碰撞；桌面、边界、蹦床参与碰撞。
- 额外接锅目标需要每口独立锅实际抵达接应区。任意指定锅掉出房间就失败。
- 磁力关、气球关、剪绳关会核对相应机制是否实际参与，单纯碰到出口不能绕过目标。

## 角色与反馈

视觉已重做为深靛漫画实验室：提高文字与状态对比度，压缩横向道具栏，模拟与结算时收起不可操作的工具，保留明确的重试入口。关卡仍使用相同物理坐标和规则。

生成素材通过 `@moecore/assets/steady` 接入：

- 用户基准用于房间中的人物；使用 SVG viewBox 映射主体，显示框为局部 `(-26,-45,52,78)`，物理半径仍为 19，没有因图片变大而扩大判定。
- GPT 自信与硬撑图用于对白反应区，根据失败或快速运动切换。
- 接应网、接应点标记、锅帽、气球绳、磁场与路径仍由 SVG 实时绘制。
- 上天组合图仍是概念稿，没有烘焙进可交互场景。

新增铁锅、气球、磁铁、蹦床、固定平台与远景六张素材，通过 `ArtSprite.vue` 的 SVG viewBox 映射到原有逻辑坐标。原始 PNG 不重采样；绳索、选择框和接应区域轮廓仍为动态界面图形。接应点的绿色占位头像已改为白龙娘图片。

素材来源、实际生成提示词与哈希见 [素材目录](../../packages/assets/steady/README.md)。静态姿态不是完整动画帧；当前没有连续骨骼动画、音效或真实模型调用。

## 本轮验证

- 16 个规则测试，包含五个挑战各自的真实通关路线和三星条件、预算与固定锅限制、进度校验和解锁，以及原有碰撞、浮力、磁力、剪绳、终局等检查。
- 8 个桌面 / Pixel 7 浏览器检查：自由模式、真实触摸拖动与撤销、暂停和运行时控制、五关连续通关、15 星、切关保留布置、刷新恢复解锁，以及用户素材显示。
- 相关类型检查、lint、构建、工作区依赖边界与冻结锁文件检查通过。
- 浏览器结果输出到独立的 `.cache/steady-campaign-e2e`；首次使用公共输出目录时出现跟踪文件丢失，换用独立目录后检查通过。
- 未重跑其他游戏全量测试，移动视口模拟不等于真实手机体验测试。

本轮视觉修改另外通过 16 个规则测试、类型、lint 和构建检查；使用应用内浏览器检查了桌面布置与成功状态、390px 手机运行与失败状态，未将前一轮八项浏览器自动检查冒充为本轮重新执行的结果。手机未出现横向溢出。截图与观察记录位于 `.cache/steady-visual/`。

下一步应通过真人试玩判断磁力关的试错成本、目标说明是否清楚，以及玩家是否愿意用更少道具重试。
