# 开局与操作审查

日期：2026-09-28。范围是当前游戏开局、地图入口、聚焦按钮操作与存档合并，
不是对全部玩法或真人趣味性的完成认证。

## 当前步骤与发现

1. 开局：1265×712 的窗口中，原先场景高度把操作区挤到首屏以外。
   现按桌面窗口高度限制游戏宽度并显示全图；手机保持原有跟随镜头。
2. 地图：原先顶部首先呈现锁定隐藏内容和创作入口，主线需要继续滚动。
   现主线章节在文档和视觉顺序上均优先，副模式仍可滚动访问。
   打开后聚焦当前关卡；Tab在地图控件间循环，Escape关闭并聚焦游戏场景。
   地图打开时后台移动控件设为 inert，方向输入不推进游戏。
3. 聚焦操作：原先方向/跳跃按钮只接受指针，空格/回车无法触发。
   现支持按住方向、松开停止、快速按键跳跃与喷射释放。
   首次测试发现 keyup 清除了尚未执行的跳跃，已修正并定向复验。
4. 多页面记录：旧页面保存可能覆盖新页面已完成内容。
   现合并通关、秘密、密钥与最快用时，计数取较大值。
   此策略避免成绩倒退，不承诺精确合计两个页面同时发生的失败次数。
