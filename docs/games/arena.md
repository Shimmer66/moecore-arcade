# 别乱生成！

入口 `/#/games/arena`，包名 `@moecore/game-arena`。

参考对象是 Unept 的 Level Devil，来源为其 Steam 商店页面（应用 3242750）。
当前有48个主线房间、独立隐藏协议与完整结局流程；参考玩法的完整性与最终品质审查仍在进行。

## 当前玩法

主线分为幻觉世界、参数世界和协议世界。每世界三扇普通门，每门五个短关，
之后是一张连续组合长关；失败只重试当前小关。累计失败三次后可跳过，
跳过不记作通关或收集，最终可在地图返回未完成的小关。
`journey.ts` 管理世界顺序，`campaign.ts` 保留稳定房间ID，已有记录不因重排丢失。

左右移动、跳跃、抵达出口。星星为可选秘密，不再锁门；撤销机制已移除。
坠落或碰到尖刺、思维链落块后，22 帧自动重生，也可按 R 或重试按钮重开。
关卡选择可以直接重玩任意已制作关卡，本地记录已通过的关卡。

八关涵盖幻觉地洞、自动补全连环尖刺、连续引用失效、移动出口与回程陷阱、
上下文删除、思维链落块、反向控制和修复引入二次问题。
机关每次重试重置，触发和运动可重复学习。

第三章增加 Token 巡逻锯、周期性 429 闸门、反重力天花板路线、
跨越长坑的移动平台及组合关。手机单人模式使用跟随镜头提高角色可见度，
双人模式显示完整场景。

第四章加入假出口、动作触发机关、只在回程触发的地洞、台阶路线、
限时试用地板与升降平台。失败原因会在重生后保留两秒；
跳跃、失败、秘密收集和通关有合成音效，可关闭，并遵守宿主音量。

第五章参数实验室包含惯性地面、量化低跳、逆风区域和自动弹射平台，
以及这些机制与假出口、限流闸门的组合。该章使用新生成的 GPT Image 实验室背景。

第六章最终评测组合了工具调用、回程限流、升降平台与假门、反重力落地、
限时低跳与最终连续障碍。章节地图按六章组织，显示通关数、秘密数和个人最佳时间。
结局区分全部通关与全部秘密，支持重新开始或返回地图补收集。

特殊协议加入会阻挡玩家的移动墙、可重复触发的空中跳跃，以及按住跳跃键或触控按钮
持续推进的喷射能力。喷射有 60 帧燃料，落地补充；长坑需控制高度节省燃料。
角色现有待机、奔跑、起跳、下落、落地、失败六种 GPT Image 关键姿态；
落地姿态持续六帧，失败姿态在坠落后仍可见。

异常样本关加入追踪角色位置的弹体，以及先预告再扩散爆炸的暗色灵感。
普通灵感可移动、跳动和生长，视觉位置和实际收集范围一致。

连续评测长关“最后还差亿点点”宽2500单位，连续组合七组机关。
镜头跟随实际世界边界；双人镜头按两人距离调整可见范围，后半段主动机关仍瞄准对手当前位置。
工坊支持1000–5000单位宽度，长画布横向滚动，导入导出保留宽度。

## 隐藏协议与分身

地图提供三条探索线索。通过带着灵感回到消失的路、越过反重力边界、
拿到证据后检验假出口这三种特定失败，分别发现密钥；普通失败不会自动送齐。
三把密钥保存后解锁隐藏协议，通关有独立结局，不作为普通主线出口条件。

分身共用移动/跳跃输入，但有独立碰撞与生死；所有副本都需到门。
先到门的副本等待其余副本，一人坠落会重试整个小队。
工坊可放置最多三个额外分身，导入导出保留分身位置。
镜头包含所有尚未到门的副本；副本进门后停止拉远镜头，剩余角色继续跟随。
隐藏结局的“再来一局”重开隐藏协议，“重返关卡地图”则返回地图。

## 无尽生成

地图顶部可开始无尽模式，输入 32 位整数种子或留空随机生成。
同一种子、同一局总是相同布局；重试不换机关，过关后才生成下一局。
前三局有两组机关，之后为三组，包含地洞、尖刺、限流闸门和移动锯的组合。
最佳通过数、当前种子、进度、秘密和失败次数独立保存，不改变主线记录。
刷新后可在地图中继续；“结束挑战”结算，“再来一局”重放相同种子。

生成器通过160组不同种子/进度的普通输入通关检查，浏览器连续四局并刷新恢复。
这是采样证据，不声称穷尽所有种子的每一种操作。

## 玩家工坊

地图中“创建关卡”打开可视化编辑器。可放置地形、起点、出口、秘密和现有机关，
选择拖动或直接调整坐标尺寸；机关可设置触发区域、动作、前置依赖、预告、
移动轨迹、周期与持续时间。支持撤销/重做与本地草稿恢复。

试玩使用正式 Matter.js 规则。数据合法不表示能够通关，当前版本实际到达出口后
才显示“已试玩通关”并启用复制关卡代码；修改版本后标记失效。
关卡代码可导入其他本地实例，没有在线作品社区。导入限制大小、对象数、数值范围、
字段和版本，外部身份/脚本字段不会进入运行模型。自制关卡成绩不写入主线。

每关保存通关次数、最快通关帧数、失败次数和已收集秘密星；秘密需带到出口才计入。
旧版通关状态会迁移，未知时间与秘密不补造。刷新后关卡地图仍显示最佳时间和秘密。
只完成最后一关时返回地图，全部已制作关卡通关后才提供完整结算。

电脑使用 A/D、左右方向键；空格/W/上方向键跳跃。手机提供左右和跳跃触摸按钮。
暂停会停止物理和机关计时，并释放移动输入。

## 实现

- `src/campaign.ts`：手工编排房间与内容合法性检查。
- `src/traps.ts`：独立触发、延迟、依赖连锁、运动和地面缺口。
- `src/runner.ts`：Matter.js 物理、跳跃缓存、落地宽限、死亡和出口判断。
- `src/CampaignGame.vue`：实际运行入口、输入、渲染、重试、选择和宿主结算。
- `src/race.ts`：同机双人共享机关、独立重生、先到终点获胜、同时到达平局。

双人按钮切换竞速。P1 使用 A/D 与 W/空格，P2 使用左右与上方向键；
触屏分别提供两组按钮。任一玩家都能触发影响双方的机关，死亡不会重置共享世界。
双人采用五局三胜，平局重赛当前局，先赢三局者获胜。重开比赛或切换模式重置比分。
每人每局可以追加一次预告落块：P1 使用 S，P2 使用下方向键，也有闪电图标按钮。
落块瞄准对手触发时的位置，双方都可躲避，也可能误伤使用者。
限时地板和临时反重力到期后，可离开触发区再进入以重新触发；
按玩家分别记录进入状态，避免双人死亡重生后失去唯一通路。

目前接入 GPT Image 第一批角色和浮岛背景，以及新生成的第二章 AI 机房背景。
素材母版、校验值及最终提示词见 `packages/assets/generated-world`。
角色动作与机关美术仍待补充。

## 验证

四十八关都有正常移动、跳跃与停顿收集秘密后抵达出口的规则测试，没有传送或修改状态。
同一批路线还通过双人物理和共享机关执行，验证一名玩家完成路线时另一名玩家留在起点的情况。
这不等于两名玩家全程竞争、各种触发先后组合都已经验收。
还覆盖坠落死亡、重置、机关依赖与内容几何。可达性不等于难度或趣味性已经验收。

```sh
npm --workspace @moecore/game-arena run test
npm --workspace @moecore/game-arena run typecheck
cd apps/web
npx playwright test --config arena-playwright.config.ts
```

浏览器用例覆盖第一关失败重生、跳跃通关、进入下一关、暂停冻结、素材加载、
窄屏无横向溢出，以及手机双人同时移动并单独跳跃的三指触摸输入。
测试截图在 `apps/web/.cache/arena-playwright`。
完整浏览器用例从空存档开始，通过真实按键沿世界顺序逐关收齐全部秘密星，
验证最终结局和返回地图；输入回放按实际游戏帧数同步，不写入运行状态或伪造进度。
