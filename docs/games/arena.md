# AI 娘：别乱生成！

入口保留 `/#/games/arena`，包名保留 `@moecore/game-arena` 以兼容现有链接。玩法已从轮流弹射改为三关横版整活冒险：玩家移动、跳跃、收集灵感星，并撤销 AI 对世界做出的荒诞改动。

## 三场事故

| 关卡                 | 整活事件                               | 玩家应对                               |
| -------------------- | -------------------------------------- | -------------------------------------- |
| 这桥，包结实的       | AI 宣称铺好的桥在预告后消失            | 提前撤销，或坠落后拉回安全位置并恢复桥 |
| 向上发展，物理意义上 | 重力反向，角色上升到天花板             | 借势拿高处奖励，再撤销回地面           |
| 地板也是上下文吗     | 身后地板逐渐消失，前方两段地板也被省略 | 跳跃跨越、继续前进，或撤销压缩恢复地面 |

每关有 3 颗灵感星，收集至少 2 颗后右侧出口开启。三关全部完成即结算；捡满 9 颗提供额外完成评价。没有限时淘汰，允许探索与补救。

## 操作

- 电脑：A / D 或左右方向键移动，空格 / W / 上方向键跳跃，E 撤销改动。
- 手机：按住左右按钮移动，按下跳跃按钮立即起跳，点击撤销处理事故；支持移动与跳跃同时操作。
- 方向按钮可聚焦并按住空格或 Enter 操作；界面主按钮可用键盘激活。
- 首次点击“开始整活”进入关卡，过关后点击“下一场事故”，第三关后查看事故报告。
- 宿主暂停、失焦暂停和重开均保留；暂停清理移动输入，恢复后需重新按方向。

## 预兆与救场

进入事件区后先显示“AI 正在优化世界”的预告，再应用变化。每关只触发一次事故。

世界发生异常时可撤销，本关恢复正常状态。正在移动时撤销不会清掉持续移动的输入。坠落超出画面后冻结现场；“拉我回来”将角色送到最近安全落脚点，保留已拾取的星星。场景修复后再次失足仍可救回，不强迫重开整关。

反重力期间可在天花板移动和反向跳跃；撤销会恢复重力并重置纵向速度。出口位于地面，需要回到地面才能进入。

## 实现与素材

`src/rules.ts` 提供纯 TypeScript 的关卡、碰撞、重力、星星、事件、救场和状态切换。`ArenaGame.vue` 管理实际输入、摄像机、演出与宿主事件，保留历史文件名。

玩家优先使用新生成的 DeepSeek 待机和奔跑关键姿态，第一关接入幻觉浮岛背景、平台与桥；资源经 `@moecore/assets/generated-world` 导出。蓝发解说头像继续复用 `HOME_ART.whaleQueue`，其他两关背景、星星、出口和事故提示仍由 SVG/CSS 绘制。该批 GPT Image 素材已按用户确认制作，详见[素材说明](../../packages/assets/generated-world/README.md)。新增批次仍先列明需求并获得确认。

收集和撤销的短提示音由浏览器 Web Audio 合成，可用音效按钮关闭，并遵守宿主音量。系统减少动态效果设置关闭装饰性抖动与角色弹跳，不关闭玩法移动。

```bash
pnpm --filter @moecore/game-arena run test
pnpm --filter @moecore/game-arena run typecheck
pnpm run build

```

规则测试覆盖起跳落地、事件预告、假桥、坠落救回、重力恢复、地板修复、出口条件和正常输入下的三关可通行性。浏览器测试覆盖桌面与触屏移动、暂停冻结、真实坠落救场、反重力取星、三关通关及重开。

这些检查验证可玩流程，不代表趣味性已经得到玩家认可。仍需要真人试玩来调整事件时机、关卡难度与笑点；目前已制作第一批场景素材和两张 DeepSeek 姿态，完整动作帧与第二、三关场景素材尚未制作。旧轮流弹射原型未作为当前模式提供。
