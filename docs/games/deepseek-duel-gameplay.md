## 1. 玩家到底在玩什么

一款随开随玩的横版 1v1 格斗游戏。双方在固定擂台上靠近、试探、挡招、抓人、连击，积攒能量后放一次带有模型梗的终结技。普通玩家连按攻击能打出三连，熟练玩家能选择提前收招、接技能、诱骗反击和大招确认。

目标体验：首次进入约 15 秒内能开打；一场通常 2–4 分钟；打赢有夸张演出，打空也有自嘲笑点；同一个角色至少有两种合理决策，不能只靠长按一个按钮通关。时间和可玩性目标需试玩验证。

首版提供 DeepSeek 娘、GPT 娘、豆包娘，全部免费可选；一张对称地图；标准难度人机对战；键盘及触屏；完整暂停、重开、再战和结算。没有随机暴击、数值养成、装备或付费强化。Claude、Gemini、Kimi、GLM、本地双人、Boss 闯关和完整训练场为后续扩展。

## 2. 一场对战的完整流程

1. **选角色**：三张卡各显示“反击 / 连击 / 均衡”、一张招牌动作和一句上手提示。默认选中 DeepSeek 娘。
2. **选对手**：默认在另外两人中随机选择并立即展示结果；玩家可改成任意已开放角色，允许镜像战。
3. **开始**：场景加载后双方站定，出现 3、2、1。玩家可打开一页操作说明；说明或暂停期间不推进倒计时。
4. **回合**：每回合 75 秒。移动、攻防和能量积攒构成全部胜负过程。
5. **回合结算**：显示胜负和一句短梗，停留 2 秒，进入下一回合；已满足整场结束条件则进入整场结算。
6. **整场结算**：主按钮“再来一把”，次按钮“换角色”，另有“返回游戏库”。展示胜负、回合比分、有效战斗时长、最高连击和成功反击/投技次数。

### 胜负与平局

- 每场最多三个回合；有人先拿两胜立即结束。平局占用一个回合，但双方都不加胜场。
- 三回合结束后，胜场多者获胜，胜场相等整场平局。因此一胜加两平也可赢下整场。
- 生命先归零者输；同一模拟帧双方生命都归零为双倒平局。所有同帧伤害统一结算，不因角色遍历顺序产生赢家。
- 时间到时比较剩余生命比例，相等则平局；最后一帧的合法命中先处理，再判断生命和超时。
- 每回合重置生命、能量、技能冷却、位置和所有场景攻击物。回合间不换角色。
- 概览的 2–4 分钟是期望时长。三回合都打满则有 225 秒战斗时间，另加少量过场。

## 3. 场地、移动与朝向

首张地图叫“服务器机房大舞台”。背景是闪灯机柜、聊天窗口和观战的小鲸鱼，地面平整；没有地形伤害、掉落道具、平台或随机干扰。装饰不参与碰撞。

| ---------- | ------------------------------------------------------------------------ |
| 逻辑画布   | 960 × 540，地面 y=450；坐标不随设备分辨率改变                            |
| 出生点     | 双方脚底中心 x=280、680，朝向对手                                        |
| 水平边界   | 脚底中心限制在 x=48–912，不会出界死亡                                    |
| 站立受击区 | 宽 48、高 96；三人相同，发饰与大头梗贴图不参与受击                       |
| 蹲下受击区 | 宽 48、高 64，底部位置不变；不能蹲躲气泡                                 |
| 步行       | 朝对手 270 单位/秒，后退 230 单位/秒                                     |
| 跳跃       | 起跳速度 720 单位/秒，重力 1800 单位/秒²；约 144 单位高、0.8 秒滞空      |
| 空中移动   | 220 单位/秒；一次跳跃，无二段跳                                          |
| 冲刺       | 双击左右方向触发；600 单位/秒持续 10 帧，再收招 6 帧；无无敌，无空中冲刺 |

双击方向的间隔不超过 12 帧，中间须释放。冲刺方向由按键决定，不能穿过地面站立的对手。冲刺期间不能攻击、防御或投技，收招完毕恢复行动。

双方地面身体互相阻挡。空中角色脚底高于对方头顶时可越过；落地重叠时向两侧各推开，碰到场边的一方停止，其余位移由另一方承担。场边不追加伤害、不弹墙。

站立、移动、蹲下、防御自由状态自动面向对手。攻击、冲刺、受击和一次跳跃开始时锁定当前朝向，直到回到自由状态。空中跨越可以制造位置变化，但首版不要求玩家学习复杂的高低防御。

## 4. 操作与输入容错

| 动作     | 键盘                             | 手机                         |
| -------- | -------------------------------- | ---------------------------- |
| 左右移动 | A / D 或左右方向键               | 左侧左右按钮，按住移动       |
| 跳跃     | W / 上方向键 / 空格              | 左侧独立“跳”按钮             |
| 蹲下     | S / 下方向键                     | 左侧“蹲”按钮                 |
| 轻击     | J                                | 右侧“打”                     |
| 重击     | K                                | 右侧“重”                     |
| 防御     | 按住 L                           | 按住右侧“挡”                 |
| 特色技能 | U                                | 右侧“技”，显示冷却           |
| 投技     | O                                | 独立“摔”按钮                 |
| 终结技   | I                                | 独立“大招”按钮；能量满后高亮 |
| 冲刺     | 双击左 / 右                      | 双击左 / 右                  |
| 暂停     | 宿主暂停按钮；Esc 由宿主统一处理 | 宿主暂停按钮                 |

此方案取代早期大纲的 J+K 投技、K+U 大招组合，手机和键盘都能单独触发。J 连点可打轻击三段，但按住 J 不自动连打；跳跃、技能、投技和大招同样只响应按下事件。持续按住移动和防御有效。

输入缓冲 6 帧：玩家略早按出的下一招，在角色可行动或可取消时执行一次；过期后丢弃。不能缓存整套连招。硬直中按下技能不会先扣能量或进入冷却。

同一帧多个新动作的优先级为：大招 → 投技 → 技能 → 重击 → 轻击 → 跳跃 → 防御 → 移动。不可执行的高优先级动作不阻断合法的低优先级动作。按住防御且新按攻击时，以攻击为主动松防；向相反方向同时输入视为不移动。

## 5. 攻防规则

| 选择     | 能解决什么                            | 对手怎样破解                       |
| -------- | ------------------------------------- | ---------------------------------- |
| 轻击     | 快速抢近身、确认命中后接短连段        | 站到范围外、格挡后等收招、预判反击 |
| 重击     | 中距离打空招、对空或击倒拉开          | 起手较慢，可被近身轻击打断         |
| 防御     | 挡住正面地面/空中普通攻击、技能及大招 | 靠近投技，或改变距离让其错失进攻   |
| 投技     | 抓住持续地面防御者                    | 预先跳开、抢先打断、短窗口拆投     |
| 跳跃     | 躲气泡、越过对手、落地攻击            | 对空重击；空中不能防御             |
| 特色技能 | 发挥角色独有强项                      | 观察起手和冷却，用对应反制         |

首版没有高低段防御区分：站防与蹲防都能挡正面普通攻击。防御时不能移动、跳跃或出招，主动释放后下一帧恢复行动；格挡硬直未结束时仍须等待。

普通攻击被挡造成 0 伤害；技能每次完整出招最多造成 5 点削血，终结技最多 10 点。削血不能将生命降到 0。没有第二条防御值，持续防御主要用投技破解。

每个攻击实例对同一目标默认命中一次；多段技能明确生成不同命中段。同一帧同时有效的普通攻击可以相互命中；不存在隐藏的“高价技能优先”规则。攻击打中身体前，先处理已激活的反击架势和防御；投技按独立抓取规则处理。

### 投技与倒地

- 投技起手 7 帧、抓取有效 2 帧，中心距离须不大于 64 单位，双方都在地面。伤害 100，之后击倒。
- 对方处于攻击起手、收招、防御自由态时可抓；不能抓受击/格挡硬直、倒地、起身保护、空中或已被抓取者。
- 投技空抓后收招 27 帧。抓中后有 8 帧拆投窗口：防守方新按“摔”可拆，双方无伤害并分开到中心距离 140；同帧互抓也算拆投。
- 投技抓取帧若同时遭受一个有效打击，打击使抓取失败。跳跃从离地帧开始免于地面投技，不因“跳键已按”提前无敌。
- 投技成功的 100 伤害在拆投窗口结束后结算，抓取演出共 24 帧，演出内双方不接收额外伤害或其他行动，计时继续。时间在拆投窗口内耗尽则取消未结算的投技并按现有生命判定。
- 击倒后落地躺 24 帧，再起身 12 帧；期间无受击判定。重获行动后追加 8 帧打击与投技保护，主动攻击或技能立即解除保护。
- 起身后不能借无敌直接进攻；向外移动、跳跃或防御可正常使用。没有倒地追打、墙角永久连段或随机受身。

## 7. 连招与防无限连

首版连招方向为：轻击 1 → 轻击 2 → 轻击 3，或轻击 1/2 → 角色进攻技能 / 大招。最后一击击倒后结束；没有重新从轻击 1 无限循环的路径。

- 下一段轻击只有在当前段命中或被挡后才能接，窗口为接触后的 10 个规则帧。新招可跳过当前剩余有效帧和收招；没接触时必须完整收招。
- 从轻击接技能/大招必须确认命中，并在命中后 8 帧内输入。DeepSeek 的防守架势不接在连段内，豆包的远距气泡也不能取消接入；GPT 的灵感连击允许接入。
- 蹲轻击命中后只能接站立重击，取消窗口 8 帧。轻击 3、站立/蹲重击、空中攻击、投技、特色技能和终结技结束后均不再取消。
- GPT 的多段技能结束后直接击倒，不沿用早期草案的“技能回接轻击”；“再生成一版”的自由取消留作后续候选。
- 连段伤害按第 1–5 段取 100%、85%、70%、55%、40%，更后各段 40%，每段向下取整。终结技作为一段取倍率下限 70%。
- 一次连续受击的总伤害上限 350；达到上限或非终结技累计五次命中时立即击倒，后续命中失效。倒地、成功防御或恢复自由行动后结束连段计数。
- 连段内每个攻击实例只结算一次，每个命中事件有独立 ID。多帧重叠、特效粒子和语音不能重复扣血。

示例：轻击三段约 123 伤害；轻击 1 → 轻击 2 → 终结技约 274 伤害。它们用于验证数值和输入，不保证所有距离下都能连上：推离后的距离仍须满足后续攻击判定。

命中停顿：普通打击双方停 4 帧，重击/反击停 6 帧，格挡停 2 帧。停顿期间世界计时、移动、攻击物与冷却一起停；允许更新按键和缓存一次后续动作，缓冲剩余时长暂停倒数。停顿不叠加，同帧取最大值。

## 8. 能量与终结技

界面标“能量”，小图标可写 Token。上限 100，回合开始为 0；生命上限统一 1000。静止、空挥和反复按键均不涨能量。

- 自己造成实际非终结技伤害：获得伤害 × 0.12；受到实际非终结技伤害：获得伤害 × 0.04。内部允许小数，界面显示整数。
- 防住一次完整出招加 2 点，同一秒最多由防御获得 4 点；多段技能不重复发放。攻击方打在防御上不获得能量。
- DeepSeek 成功架势额外加 12 点，每次技能最多一次；架势本身挡下的伤害不再按防御发能量。
- 终结技伤害、削血、演出、拆投不发能量。投技完成后的实际伤害按正常比例发能量。
- 发动终结技立即扣 100 点，空放、被打断或被格挡不退款。冷却中/能量不足/状态不合法的无效输入不扣资源。

所有终结技有可见起手、可被正常防御，没有开场无敌。它们主要用来确认连招、惩罚大空招，不能一满槽就保证命中。

命中后锁定双方进入统一 1.2 秒特写，伤害在确认命中帧一次结算，特写里的多拳只是演出。生命归零也要演出完才显示 KO。特写期间计时、冷却、投射物全部暂停，清空战斗输入；结束后受击者进入击倒，释放的技能不会自动续发。

双方同帧互中时先统一扣血；如果终结技使用者也被有效攻击打中，则不进入单方特写，按正常击倒表现，终结技伤害照常结算。双方同帧大招命中也如此；避免因播放顺序吞掉一方的命中。最后一帧命中的大招先结算伤害，特写结束后再宣布 KO 或超时胜负。

用户可在开战前关闭“大招特写”；战斗时长仍固定暂停 1.2 秒，以简短镜头代替，不改变反应窗口。首版不做对局中随意跳过改变同步节奏。

## 9. 首发角色：DeepSeek 娘

定位：中距离反击。推荐玩家先用长重击试探，看到对手冲上来时开架势；遇到不肯出拳的对手，主动走近用轻击或投技。

### U：深度思考中（推演架势）

- 起手 4 帧，接招窗口 12 帧，失败后收招 24 帧；冷却 180 帧，从技能合法发动帧开始。
- 接一次正面的普通打击、技能打击或气泡。不能接投技和终结技；接招窗口以外照常挨打。
- 成功时取消该次命中并消除被接住的投射物，获得 12 能量，进入反击：5 帧起手、3 帧有效、22 帧收招，140 伤害、距离 140、命中击倒、被挡硬直 16 帧。技能削血按统一 5 点上限。
- 反击不追踪、不瞬移；远处发来的气泡可以被接掉，但对手太远就不会被反击打中。成功接招后没有持续无敌，反击起手仍可被其他合法打击打断。
- 演出：脑袋转圈“正在思考”，成功瞬间甩字“想完了”；旁边小蒸锅弹出迷你拳套，跟着主拳同时击中，**不增加第二次伤害**。蒸馏台词：“学会了，现学现揍。”
- 失败台词“思考了个寂寞”，被投技破解时“你不按题目来啊？”仅偶尔触发，不延长收招。

### I：答案收束 · 专家会诊

前摇 16、有效 3、空放/被挡收招 40 帧；攻击距离 170；原始伤害 280；被挡硬直 18 帧。命中后两个小鲸鱼专家从一排座位冲出来，抡出巨锤，思维线合成鲸鱼光影，最后定格“这题我会”。所有演出合计一次 280 伤害。

优点：守住一次进攻就能获得伤害和能量。弱点：架势失败硬直长，投技与大招直接破解。人机不能凭玩家按键立即开架势。

## 10. 首发角色：GPT 娘

定位：近身连击。轻击三段对应“首先、其次、最后”；玩家可在第二下命中后选择接技能或满能量大招，承担主动贴近的风险。

### U：灵感连击

- 冷却 240 帧，发动即开始；起手 12 帧，起手最后 8 帧总共向前移动最多 120 单位，受到身体阻挡，不能穿人。
- 第一段有效 3 帧，原始伤害 65、距离 82、命中硬直 18、格挡硬直 10 帧；两段之间间隔 6 帧。
- 第二段有效 3 帧，原始伤害 65、距离 96，命中击倒、被挡硬直 14 帧；随后收招 26 帧。第一段的水平击退仅 4 单位，方便第二段接上。
- 出招后不能主动取消第二段；被对手击中则整招中断。第一段打空，第二段仍会出；每段按真实碰撞独立判断。
- 可由轻击 1/2 的命中取消接入，技能结束不能接回轻击。未被打断、近身两段全中约 120 伤害，接入连段后按累计段数继续衰减。
- 演出：两拳各甩出“第 1 版”“最终版”草稿，背景冒一句“再生成一版！”；整套被挡后飘“上一版比较好”。

### I：无限联想 · 综上所述

前摇 14、有效 4、空放/被挡收招 42 帧；前摇最后 10 帧总共向前移动最多 180 单位；攻击距离 120；原始伤害 280；被挡硬直 18 帧。命中后草稿快速换三版，最后把“综上所述”当印章砸下，字幕“已发送”。

优点：贴近后命中确认简单。弱点：远处威胁小，技能和大招被挡都有明显反击空当。连点轻击不能凭空吸附目标。

## 11. 首发角色：豆包娘

定位：均衡、上手最简单。远处放气泡逼对手跳，近处普通攻击，对方跳进来用蹲重击对空，防御者用投技打开。

### U：包的 · 对话气泡

- 起手 18 帧，释放气泡时有 1 帧发射动作，随后收招 22 帧；冷却 108 帧，从技能发动开始。
- 气泡中心生成在角色面前 48 单位、离地 52 单位处，碰撞半径 22，以 360 单位/秒水平移动，最多存活 150 帧；碰到场边或目标即消失。
- 原始伤害 100，命中硬直 22 帧、击退 70 单位；格挡硬直 12 帧、削血最多 5 点。站防和蹲防都能挡，蹲下不能躲，跳跃可越过。
- 每人最多存在一个气泡，即使冷却好了也要等旧气泡消失才能再次发射；按钮显示“气泡在场”。镜像对战的两枚气泡相碰同时消失。
- 普通拳头不会消除气泡。释放后角色被打中，气泡仍继续移动；回合结束才统一清除。不能从轻击取消接气泡，避免远距循环压制。
- 演出：发射举“包的”，命中“收到”，打空不立即出梗；只有气泡飞出场时偶尔显示“没包住”，防止持续刷屏。

### I：热聊时刻 · 省字不省拳

前摇 16、有效 3、空放/被挡收招 38 帧；攻击距离 180；原始伤害 280；被挡硬直 18 帧。命中后“我用最直白最不绕弯子……”的气泡被压缩成一个“揍”字，变成豆包拳套砸下，收尾“包办了”。

优点：距离控制直观、近远都有办法。弱点：气泡慢且有在场限制；对手跳过后，发射收招会暴露破绽。她的大招不是全屏追踪。

## 12. 人机行为

首版只开放一个“标准”难度。使用固定规则机器人，读取公开战局；不连接模型 API。机器人使用相同伤害、速度、技能冷却与输入约束。

- 对手状态观察使用至少 15 帧前的画面状态，战术重新决策间隔在 12–24 帧中取值；不读取玩家按键、输入缓冲或下一次选择。
- 敌人距离超过 260 时以接近为主；中距离试探、后退或使用角色招式；近身时在轻击、防御、投技、短后退间选择。
- 对手持续自由防御超过 0.6 秒且自己在抓取距离内时，增加投技倾向；无法立刻得知玩家刚开始防御。
- 看到早前的长起手可尝试防御；短轻击主要靠预先防御，不声称机器人能在 6 帧内读招。每次对可见威胁的防御选择有约 35% 放弃概率，供后续调难度。
- DeepSeek 偏中距重击和预判架势；GPT 偏接近及轻击确认；豆包偏气泡与对空，但不可只后退放气泡。
- 自己的攻击反馈使用单独的 4 帧延迟，不受战术决策间隔阻塞；届时仍在合法取消窗口才能选择接招。标准难度只在约一半的合法机会执行技能确认或轻击第二段后的大招确认，其余走普通三连或停手。能量、距离和当前招式照常检查；对手防御时不会拿到“命中”反馈。
- 会出错、会打空；不故意在玩家残血时停手，不在玩家连胜后暗改伤害。随机使用可记录的种子，便于复现问题。

轻松、困难难度未来只调整观察延迟、决策频率、失误概率和连段选择，不偷加生命或伤害。首版失败面板提供“再战”和简短建议，例如“她一直防御，可以靠近按摔”。

## 13. 梗、声音与界面

梗系统只订阅已发生的命中、落空、反击、KO 等事件，不反向改变伤害和时间。当前角色的嘴硬与被打脸各准备至少三句；普通语音全局间隔至少 8 秒，同句每场最多一次。大招台词可每次出现，但不会和解说叠播。

| 场景         | 表现                                       |
| ------------ | ------------------------------------------ |
| 连续三次空挥 | 小字幕“空气：已读不回”，冷却 20 秒         |
| 满槽大招落空 | “生成 0% 伤害”，不伪装成真的付费扣款       |
| 成功反击     | “这也能算到？”，出现在角色上方，不盖住对手 |
| 残血翻盘     | 结算才说“差点没包住”，不插入战斗           |
| 双倒         | “都别装了”，回合比分清楚标平局             |

梗字幕每条最多停留 0.8 秒，同屏最多一条；优先级为 KO/回合结果 > 大招 > 反击 > 落空吐槽。倒计时、技能冷却、格挡火花和危险动作的辨识度高于梗图。全屏大头插片仅在已确认的终结特写内使用。

顶部固定显示双方头像、名字、生命、回合胜点和时间。能量在各自血条下方；特色技能冷却在操作按钮与角色侧的小标记上同步显示。“大招可用”只脉冲一次，之后静态高亮。

手机横屏时场景居中，左右控制分置；竖屏时场景在上、控制区在下，不强制旋转、不弹反复提醒。关键触屏按钮至少 48 × 48 CSS 像素，主攻击至少 56 × 56；320 像素宽时控制区改为两组多行，不能裁掉投技和大招。支持按住移动时同时点击跳跃、攻击；失焦与触点取消清理所有按住状态。

设置提供音效、语音、镜头震动与大招特写开关，首次默认音效开启、语音低于打击音；遵守宿主总音量与减少动态效果设置。降低动效时关闭震动、闪屏和装饰缩放，仍保留必要的命中火花与动作前摇。

## 14. 首次上手与可重玩内容

选角卡每人只强调一个动作：DeepSeek“对手出拳时按技反击”；GPT“近身连点打，命中后接技”；豆包“远处按技，跳过来的对手用蹲＋重”。开始页提供“看操作”，用攻击、防御、投技三张图解释克制关系，随时可关闭。

首版重玩动力是换对手、换打法、打出更稳的反击和更短的通关时间。角色全部开放，不设每日任务与强制解锁。最高连击与对局数据先在本场结算展示；本地长期记录待现有存储服务真正接入后再做，不能声称已保存。

一段典型交手：豆包先放气泡，DeepSeek 可以跳过去抢位置，也可以开架势消掉气泡积攒能量；豆包发现对方习惯接气泡后，改为靠近假装出招，等架势露出破绽再抓。DeepSeek 下一次可以提前轻击打断靠近，命中第二下后再判断是否接大招。对手的习惯让下一次选择发生变化，梗图跟随这些成功或失误出现。

再战创建新的会话，保留本场角色和对手选择，清零生命、能量、胜场、输入与攻击物。换角色返回准备页。宿主“重开”同样重置整场并沿用当前双方选择；退出复用宿主确认流程。

## 15. 后续四人怎样扩展

这些是设计方向，不加入首版按钮或假入口。每位仍优先一个特色技能加一个终结技，完整复制技能、姿态切换和布阵系统逐项验证后再扩展。

| 角色   | 玩法差异                           | 优先落地的专业/大众梗                        | 新增规则风险                                   |
| ------ | ---------------------------------- | -------------------------------------------- | ---------------------------------------------- |
| Claude | 接触式防守与推离，重击反打         | 终结技“物理对齐”：水平尺把人拍平             | 必须和 DeepSeek 的主动反击窗口区分，避免只换皮 |
| Kimi   | 长距离、慢收招，控制水平空间       | “省流炮”：卷轴压成纸团；重击“有出处才下重手” | 长距离不能覆盖跳跃与贴身两个弱点               |
| Gemini | 地空不同招式，利用跳跃改变攻击角度 | 双子互相甩锅、纳米香蕉、多模态配音延迟       | 首先验证单招地空变体；香蕉地面陷阱后置         |
| GLM    | 提前放置可见格点，预测走位后引爆   | “这题有谱”、梯度升天拳、四比特残影           | 陷阱上限、到期、边界和起身保护都要独立验证     |

幻觉核心留作以后街机关卡 Boss，用“画错的怪物”“输了但报表赢了”等梗。首版三人对打成立前，不叠加 Boss 的专属规则。

## 16. 开发顺序与验收证据

| 顺序 | 交付           | 依赖与完成条件                                                             |
| ---- | -------------- | -------------------------------------------------------------------------- |
| 1    | 对称灰盒战斗   | 移动、身体碰撞、跳跃、普通攻击、防御、投技、倒地；两方同帧公平处理         |
| 2    | 连段与整场规则 | 命中取消、伤害衰减、三回合、超时/双倒、能量和终结技锁定均可复现            |
| 3    | 三名角色       | 加入三项技能、重击差异和三个大招；确认反击/气泡/多段交互                   |
| 4    | 人机与输入     | 标准机器人、键盘和触屏均可完整打完一场；不读玩家未来输入                   |
| 5    | 美术与梗演出   | 素材对应判定、台词频率、手机布局、音效与减少动效设置                       |
| 6    | 真人试玩调参   | 验证三种打法、重复按键是否统治、看招是否清楚、手机是否误触；按证据调整初值 |

规则验证至少覆盖：相互命中/双倒、最后一帧超时、格挡削血不致死、投技拆投与时间到、连段边界、技能在冷却中不消费、气泡消失/镜像碰撞、架势对投技/大招无效、大招被打断不退款、镜头与特效不重复发伤害。

浏览器验证至少覆盖：选角到再战完整流程、键盘和触屏同时移动攻击、暂停与恢复、失焦不自动续打、缩放布局、关闭语音/动效、回合切换后无旧投射物、宿主重开与结束事件仅发送一次。实现时遵循现有游戏 SDK，不把模拟状态塞入宿主。

首轮真人试玩建议 5–8 人，包含首次接触格斗和熟悉此类玩法的玩家。记录首次主动出招用时、能否说明“防御用投技破解”、误触、看不清的招、平均有效回合时长和再战意愿。目标是多数人无需解释能完成一场、能说出本角色的打法，且没有一个动作明显替代其他选择；未试玩前不宣布这些目标已达成。

实施前仍需确定角色精灵的最终美术样式和目标设备性能预算，这不影响按本文制作占位战斗切片。不会因本设计文档自动开始代码开发、素材生成、提交或发布。
