# 鲸鲸的灵感长队

入口：`/#/games/whale-queue`。游戏包为 `@moecore/game-whale-queue`，规则位于 `games/whale-queue/src/rules/`，Vue 界面位于 `src/components/WhaleQueueGame.vue`。

当前是单局原型，不需要模型账户，不连接真实 AI API。

## 目标与规则

| 项目     | 当前实现                                                  |
| -------- | --------------------------------------------------------- |
| 棋盘     | 16×16；开局队伍长度为 3，朝右前进                         |
| 胜利     | 收集 30 颗灵感星                                          |
| 分数     | 每颗星 10 分                                              |
| 前进     | 常态每 200ms 前进一格                                     |
| 转向     | 下一步采用最近一次合法转向；不能直接掉头                  |
| 失败     | 撞到边界、礁石或仍被身体占用的格子                        |
| 增长     | 每收集一颗星，队伍增长一格                                |
| 深度思考 | 消耗一次充能，持续 3 秒，期间每 400ms 前进一格            |
| 充能     | 每集齐 5 颗星且当前无充能时补充一次，最多存一次           |
| 摘要贝壳 | 在第 10、20 颗星后请求生成；吃到后缩短 3 格，最低长度为 3 |

星与贝壳只生成在可用空格。规则内置四种礁石布局，使用会话种子选择布局和物品位置；同种子可复现，不代表所有随机局面已经人工验证通关。

## 操作

- 点击“开始收集灵感”开始；准备状态下点击方向键或使用方向输入也会开始。
- 电脑使用方向键或 WASD 转向，空格用于开始或消耗已获得的思考充能。
- 手机使用棋盘下方四向按钮，点击“深度思考”使用充能。
- 进行中“这一局重来”直接重置本游戏状态并开始。宿主工具栏的重开则经过确认并创建新会话。
- 首次进入显示准备状态；宿主重开后的 `attempt > 1` 会自动开始。

## 暂停与结果

宿主通过 `paused` 停止规则推进和有效对局计时。组件每 50ms 驱动一次规则时间累积；暂停时跳过推进，失焦后需由用户明确恢复。

碰撞或胜利后通过 `finish` 返回结果、摘要和角色结尾图，由宿主统一展示结算。卸载时清理键盘监听与计时器。当前没有跨刷新存档或续玩。

## 界面与素材

外围颜色、按钮和操作栏遵循 [UI 规范](../ui-guidelines.md)。桌面棋盘与操作说明并排；手机的开始按钮和方向键放在棋盘后，说明放在操作区之后。

棋盘采用 CSS 简洁外框和数据海背景，角色、星、贝壳、礁石及特效通过 `@moecore/assets/whale-queue` 获取。旧花边框图片仍保存在资源包中，当前组件没有使用。

开发和公开试玩构建均显示当前素材，保留候选审核状态；来源与许可说明见[素材清单](../../packages/assets/CREDITS.md#鲸鲸的灵感长队素材包)。
