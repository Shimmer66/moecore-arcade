# AI 娘消消乐

状态：已接入 Vue 3 可玩原型，包含一关、六类棋子和完整结算；未达到公开发布验收。

采用交换式三消，不是连连看或暂存槽叠层三消。玩家交换相邻棋子，在有限步数内收集指定角色棋子。
下面数值是原型起点，尚未经试玩验证。

## 最小规则

| 项目       | 目标行为                                                 |
| ---------- | -------------------------------------------------------- |
| 棋盘       | 8×8，默认六类棋子，教程可以缩减生成池                    |
| 操作       | 点击两格或向相邻格拖动，仅允许上下左右相邻交换           |
| 有效交换   | 形成新的匹配才扣一步；无匹配回退且不扣步数               |
| 匹配       | 横向或纵向连续至少三个同类棋子；交叉重叠只计算一次       |
| 连锁       | 消除、下落、补齐后继续检测，同一次操作的连锁不额外扣步数 |
| 目标       | 收集指定角色棋子，目标角色必须存在于本关生成池           |
| 步数       | 原型初值 20，后续按关卡配置                              |
| 判胜       | 全部连锁结束后先检查目标，最后一步完成目标仍通关         |
| 判负       | 连锁结束，目标未完成且步数为零                           |
| 初始棋盘   | 不存在立即匹配，且至少有一次有效交换                     |
| 无路可走   | 剩余步数大于零时免费重排，不改变目标进度和步数           |
| 重排上限   | 随机重试必须有上限，失败后构造满足约束的棋盘             |
| 输入互斥   | 交换、消除、下落和补齐期间不接收新交换                   |
| 暂停与退出 | 暂停不推进规则，首版不提供刷新续玩                       |

规则层使用纯 TypeScript，不通过 Vue 或 CSS 动画回调计算匹配、步数或胜负。
测试不依赖真实图片、浏览器 GPU 或音频。

## 原型顺序

1. 棋盘生成、匹配检测、有效交换枚举与确定性测试用随机源。
2. 交换、消除、下落、补齐、连锁和有限重排。
3. 收集目标、步数、最后一步判胜与结算。
4. Vue 棋盘、输入互斥、暂停、重开与卸载清理。
5. 五个教学与验证关卡、关卡进度、设置和设备适配。

目前第 1 至 4 条已实现；第 5 条中的五关内容、教程、音效和进度保存尚未完成。
`playMove` 统一计算交换、消除、下落补齐、连锁、收集和结算，再把棋盘快照交给 Vue 显示。
一次操作最多计算 32 轮连锁，超过上限或无有效交换时有界重建棋盘；重建不额外计分或扣步数。
原型目标为 20 步内各收集 12 枚 DeepSeek、GPT、Kimi 棋子，属于待调优的关卡参数。
默认生成与强制构造路径保留种子 1..1000 的不变式测试，新规则覆盖最后一步判胜和连锁上限。

Vue 界面支持相邻点击、指针拖动、键盘方向键移动焦点、提示、减少动态效果和暂停。
重开由宿主创建新会话；组件卸载后取消动画帧，不写入旧结果。
本地开发使用素材包的头像棋子，正式构建只使用自制缩写棋子。
头像与符号两套皮肤仍对应六类角色，不混成十二类；素材单测不能替代授权审核。

## 首个可玩版本

目标包含一张棋盘、六类棋子、五个关卡，以及关卡选择、对局、暂停和结算。
设置保留音量、减少动态效果和重置本地记录。
不加入特殊棋子、应援技能、障碍格、体力、付费道具、排行榜或账号。

## 验收清单

- 初始无现成匹配且存在合法操作，随机失败不会无限重试。
- 非相邻、斜向、动画中和重复输入均不提交新操作。
- 有效交换扣一步；回退不扣；连锁不重复扣。
- 交叉匹配不重复计数，目标进度来自真实消除结果。
- 最后一步完成目标时判胜，无路可走时保持进度。
- 暂停不推进规则，重开后旧回调不影响新局。
- 桌面和触摸可操作；实际存储异常不阻止游玩。
- 所有发布资源可追溯，未审核资源与私密授权证据不进入产物。
