# AI 娘弹珠乱斗

状态：后续玩法参考，未创建游戏包。

此页保留《AI看板娘小游戏开发方案书 V1.0》的主要设计，供未来立项使用。
当前工程沿用附件 README 的合集结构，首个包为消消乐；本页不表示弹珠玩法已获同步实施或公开发布承诺。

## 核心体验

从六位角色选三位组成玩家队伍，剩余三位由规则机器人控制。
双方轮流向后拖拽蓄力并弹射一个在场角色，将对方圆形底座撞出安全区。
所有角色可以互相碰撞，误撞队友照常淘汰。
没有血量、暴击、复活，也不调用大模型。

| 规则   | 原型设计                                        |
| ------ | ----------------------------------------------- |
| 回合   | 严格交替，双方各行动一次为一轮                  |
| 越界   | 圆形底座与安全矩形完全不相交；立绘不参与碰撞    |
| 判胜   | 整次行动稳定后统一判断，同次双方全部出界为平局  |
| 上限   | 最多 12 轮，先比在场数量，再比到中心的平均距离  |
| 安全区 | 第 9 至 12 轮前逐次收缩，统一检查两队后判胜     |
| 超时   | 决策时间初值 12 秒，超时跳过，不强制随机发射    |
| 运动   | 固定物理步长，稳定阈值和最长 6 秒兜底需实际验证 |
| 技能   | 后续每人每局一次，需分别定义消耗、取消和到期    |
| 机器人 | 只读公开局面，限制搜索预算，拒绝过期行动        |

## 阶段范围

首个验证版本只做对称地图、几何占位、基础弹射、越界、回合和机器人，不启用技能。
角色贴片随底座移动但保持直立。加入技能前先验证固定步长、重复发射、同时出界、暂停恢复与重开清理。

后续技能方向包括范围推力、质量增益、攻守切换、队友支援、障碍反弹和几何参考线。
各角色常态碰撞大小及物理参数保持一致，不以真实模型排名决定游戏强弱。
原文中的参数、工作量和时间安排均为估算，实际实施前重新确认。

## 独立验证

该玩法需独立的物理适配和状态机，不能复用消消乐的胜负逻辑。
模拟世界不得修改真实战局；行动和结果只接受一次，失焦时暂停并清除未提交瞄准。
最终设备与素材范围在该玩法实施时明确，不以本次脚手架冒烟测试代替游戏验收。
