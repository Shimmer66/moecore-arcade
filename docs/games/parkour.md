# AI 娘星潮跑酷

状态：已接入游乐园的 Vue 可玩原型，尚未完成真实设备和难度平衡验收。
入口为 `/#/games/parkour`，与消消乐独立加载、独立保存局内状态，不读取其他游戏的规则。

## 一局的目标

选择 DeepSeek、GLM、GPT 或 Claude，穿过 1,200 米星潮航线。四个角色使用相同的碰撞体和规则，
当前差别仅为外观。倒计时结束前不推进跑道。

| 机制       | 当前实现                                                                   |
| ---------- | -------------------------------------------------------------------------- |
| 跑道       | 自动前进，从 6 m/s 逐渐增加，基础上限 12 m/s；400 和 800 米变更段落标记    |
| 障碍       | 地面障碍需跳跃，低空障碍需滑铲；形状与装饰图不决定碰撞边界                 |
| 二段跳     | 空中可再按一次跳跃，每次落地重置；长按不会自动连续起跳                     |
| 下落与滑铲 | 空中向下输入快速落地，地面按住下键保持滑铲；触屏按钮/下滑触发短时滑铲      |
| 容错       | 三颗心，碰撞消耗一颗并中断连击，随后 1.2 秒受伤保护；零颗心结算            |
| 连击       | 收集物和越过障碍增加连击，每 10 连增加一档倍率，最高 5 倍                  |
| 冲刺       | 星币和越障积攒能量；100% 时主动消耗，持续 1.4 秒、速度提高 25%，可冲破障碍 |
| 收集路线   | 地面障碍附近为抛物线星币，低空障碍下是低位星币；部分障碍后方有高空星星     |
| 道具       | 磁铁吸取附近奖励 7 秒；护盾挡一次碰撞；爱心恢复体力且不超过三颗            |
| 局内挑战   | 越过 10 个障碍、收集 30 星币、达到 25 连击，各奖励 300 分且只结算一次      |
| 结束       | 到达终点为成功，体力耗尽为失败；得分包括距离、收集、越障与挑战奖励         |

这些机制提供额外选择，但“有趣”仍需要试玩反馈验证，当前不声明留存率或难度平衡已达标。
暂不做角色战力、付费复活、无尽排行、账号或音效系统。

## 操作

- Space、↑ 或 W：跳跃；空中松开后再按可二段跳。
- ↓ 或 S：滑铲/快速下落；松开后恢复站立。
- Shift 或 X：能量满时冲刺。
- 触屏：跳跃、滑铲、冲刺按钮；赛道内轻点/上划跳跃，下划滑铲，右划冲刺。
- 宿主提供暂停、重开、返回；失焦自动暂停，恢复焦点后仍需主动继续。

## 星潮灯塔的故事

这是本项目的原创虚构剧情，不是角色对应公司或模型的官方设定。
星潮灯塔熄灭，最后一艘归航船困在夜海。四位伙伴带着星核出发，沿途找回散落的星光。
每位角色有自己的开场台词，但不因此获得不同强度的能力。

1. **珊瑚浅湾，出发**：选择伙伴，了解归航船的处境，带着星核沿海岸前进。
2. **400 米，灯塔的秘密**：GLM 在遗迹星图中发现，灯塔把光借给了每个迷路的人。阅读暂停跑道，中继站恢复一颗心。
3. **800 米，一起回家**：Claude 看见旅人们点起小灯汇成顺流。阅读暂停跑道，冲刺能量充满。
4. **1,200 米，归航**：结尾由实际收集量决定，不由随机文本决定。

| 条件                  | 结尾                                                         |
| --------------------- | ------------------------------------------------------------ |
| 未抵达终点            | 潮水里的约定：伙伴们接住角色，保护星核，留下下一次出发的约定 |
| 抵达终点，星币不足 30 | 第一盏灯：星核点亮一小束光，归航有了方向                     |
| 抵达终点，星币 30–59  | 归航之光：散落星光连成航线，船只平安返回                     |
| 抵达终点，星币至少 60 | 星潮长明：旅人们留下小灯，灯塔不再独自发光                   |

章节补给只发放一次，继续旅程后有短暂保护时间。阅读、暂停和倒计时不计入有效对局时长。

## 规则与生命周期

`src/rules` 为纯 TypeScript，复用 `feat/parkour` 的固定 1/60 秒积分与 swept AABB 碰撞。
`adventure.ts` 在基础模拟上增加资源、容错和奖励；原核心算法与原始回归测试保留。
Vue 按帧展示快照，不让 CSS 动画决定碰撞或得分。

一次较长的帧间隔最多处理 0.1 秒，避免阻塞恢复后跳过整段障碍；暂停不补算后台时间。
组件卸载后停止动画帧、移除键盘监听、断开尺寸观察器，并丢弃过期素材加载结果。
`finish` 只在终局发送一次，由宿主再校验会话。

## 素材

用户提供的 400 张图片收录在 `packages/assets/parkour`，按 manifest ID 延迟解析所需 URL。
实际场景只引用选中的姿态、地块、障碍和道具，不把 400 张同时加载到画面。
图片保留原生尺寸；角色使用脚底锚点和状态切换，不将静态姿态宣称为连续动画。

来源状态为 `generated-pending-review`。开发服务可看角色美术，正式构建使用自制几何图形，
不自动把本次素材上传或发布。素材原始清单、质量记录与本项目测试结论分别保留。

## 验证

- 基础规则：保留 512 个种子的全程模拟、固定输入回放、碰撞与间隔边界测试。
- 新机制：二段跳限制、快速下落、三次受伤、受伤保护、护盾、能量消耗、收集和挑战奖励去重。
- 浏览器：角色选择、键盘和指针操作、倒计时、暂停、重开、完整失败结算及跨游戏切换。
- 视觉：桌面、手机和 320px 窄屏检查素材加载、帧间移动、控件尺寸与横向溢出。

模拟器和桌面浏览器的移动视口不等于真实手机性能验收；公开发布前还需素材审核、真机试玩和操作节奏调整。
