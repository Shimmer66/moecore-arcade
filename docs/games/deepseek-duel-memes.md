# 《推演对决》模型梗素材库

2026-09-27 新增白饭、稳稳接住、唐包三种可操作机制与同机双人，详见[搜索资料与规则落点](duel-meme-research-2026-09-27.md)。F / P2 数字9触发，饭碗可以被打翻、下落对手可以被接住、回旋气泡可能返回砸自己。

随后加入三个原创双人互动：投技抢饭、主人命中夺回；带饭碗或额外气泡令接人中的 GPT 过载；重击把气泡退回发射者并触发“挨打已签收”。具体操作与限制见[游戏说明](../../games/duel/README.md#双人互坑互动)。

## 已实现的原创互动：让玩家把梗打出来

用户明确方向：“我们是在创造 meme”。创作重点是角色特征在实际交互中变成荒诞结果；先有能看懂的行为，再由短台词收尾。

前三种互动及“已读已堵”仅在有效伤害命中时产生；格挡、反击抵消、空挥不伪造命中。包子表现跟随倒地状态，不改变碰撞与伤害；减少动态效果时取消滚动和漂浮，仍保留识别图形。场景重置后清除旧互动。

“缓存命中”记忆按回合清空，不额外增加伤害；练招房新增“反复重击（练反击）”木桩，便于重复体验。“版本回滚”只倒放视觉残影，不恢复位置、生命、能量或冷却；被打断的变招不会触发。“嘴硬结算”不会改变胜负，练招房和双方平局不触发。六张新图与完整提示词见[素材说明](../../packages/assets/duel/README.md)。

DeepSeek 三连现在为前两拳、第三脚，空中攻击也使用踢击。创作要继续围绕“角色一贯的特点 → 被对手利用或打断 → 意外但能解释的后果”，形成可由玩家复现的场面。

状态：2026-09-26 的玩法文案研究与原创提案；部分首发梗已用于三人可玩原型，其余为候选。服务于低门槛、手机端、短视频传播的搞笑格斗体验。“下沉”在这里指不要求玩家懂模型版本、API 或程序员黑话；看画面和听一句话就能笑。

首发角色的正式技能、数值和演出落点已写入[详细玩法规格 v1](deepseek-duel-gameplay.md)。本库继续保留候选方案；“再生成一版”自由取消、复制敌招等候选不因收录而自动进入首版。

## 筛选办法

- **先打中，再出梗**：招式轮廓、攻击方向和可防方式必须先看懂。笑点放在命中、打空、反打和结算的半秒反馈里。
- **专业梗也能当主菜**：允许“蒸馏”“量化”“梯度爆炸”等直接成为招式名，配一个看得懂的动作和口语短句。不了解术语的玩家也能从蒸锅、像素小人、爆炸等画面获得笑点。
- **每人一个招牌笑点**：观众截一帧就能认出是谁。角色会自嘲，落空也有反转，不把对手或玩家单方面当笨蛋。
- **事实与二创分开**：下面的“观察”只表示相关话题确实有传播或产品联想；游戏台词、招式、角色性格都是原创演绎，不能读成真实产品能力评测。

## 面向低门槛传播的文案规则

1. 主画面允许短的专业招式名，同时给出直观动作与口语台词。较长解释放角色详情；玩家不认识“Token”“上下文窗口”也能笑。
2. 一局最多触发两三种通用梗，不连续重复同一句。命中字幕不盖血条和下一次攻击的预兆。
3. 每个角色有一组“嚣张台词 + 打脸台词”。打赢时帅，打空时丢人，这种反差比单纯嘲讽对手更耐看。
4. 视觉可以故意土：大头抠图、荧光描边、夸张的打字机音效、突然出现的聊天框。攻击判定和控制响应仍要扎实。
5. 热词放在可替换的字幕库里；角色招式名用“深度思考”“再生成”“拒绝申请”“香蕉皮”“前文提要”“离谱”“包的”等耐久度更高的意象。
