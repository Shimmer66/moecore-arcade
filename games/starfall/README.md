# 荒星回响：第七码头

入口：`/#/games/starfall`。

原创本地双人浏览器格斗游戏。美术方向取自沙漠旅途、漫画分镜、夸张姿势、近身回响体交锋和时间压迫感，但角色、回响体、场景、招式、台词与素材均为本项目原创，不复用现成作品名称或受保护素材。

## 玩法

- 三局两胜，每回合 45 秒；时间结束比较剩余生命。
- 移动、跳跃、轻拳、重击、防御和后撤闪避均可随时使用。
- 命中或防御会积攒回响槽。30% 以上可发动四段回响连拳；100% 时同一按键自动发动五段必杀。
- 防御大幅降低正面伤害，闪避前半段无敌。连续命中显示连击数。

## 操作

| 玩家    | 移动  | 跳跃 | 轻拳 | 重击 | 回响 / 必杀 | 防御 | 闪避 |
| ------- | ----- | ---- | ---- | ---- | ----------- | ---- | ---- |
| P1 琥珀 | A / D | W    | F    | G    | H           | S    | Q    |
| P2 靛青 | ← / → | ↑    | 1    | 2    | 3           | ↓    | 0    |

数字键同时支持主键盘数字行与数字小键盘。较窄窗口显示双侧触屏按钮，但桌面双键盘是首要体验。

## 实现与验证

`src/rules.ts` 是无浏览器依赖的 60 Hz 状态推进器；`StarfallGame.vue` 负责输入、漫画舞台、原创 CSS 角色和宿主结果事件。首页封面为 `packages/assets/resources/starfall-cover.svg`。

```sh
pnpm --filter @moecore/game-starfall test
pnpm --filter @moecore/game-starfall typecheck
pnpm run build
pnpm --filter @moecore/web exec playwright test starfall.spec.ts
```

当前角色采用代码绘制的关键姿势和补间，不是逐帧动画。首版没有联网模式、角色选择、音频或训练模式；招式数值仍需更多真人对战调优。
