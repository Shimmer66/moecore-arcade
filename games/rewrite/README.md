# AI 娘闯关：模型战争

原创 AI meme 跑跳射击战役，使用项目已有看板娘形象。八个节点必须击败各自的 Boss 才能推进，终关结束后向宿主提交战役成绩。当前已支持横向突击、纵向攀升、纵深基地及本地双人协作；“完整复刻并超越魂斗罗”的目标仍在推进，不能将当前版本称为已完成该目标。

## 操作与规则

- WASD / 方向键：移动、八方向瞄准；站定按下卧倒，空中可以向下射击。
- J：按住连续开火；K / 空格：跳跃；L：手雷；Shift：定点瞄准。
- 标准手柄：左摇杆/十字键移动与瞄准，A跳跃，X射击，B手雷，右肩键定点瞄准；双人使用前两个手柄。
- 高台上按下 + 跳：穿过当前平台，落向下层；静态地面、塔顶 Boss 地面和纵深基地仍正常跳跃。P2 使用方向下 + 句号，触屏可同时按卧倒和跳跃。
- 触屏方向盘与三个动作键支持同时按下；方向手指可在九宫格内滑动换向，滑出方向盘会释放。动作键的小范围漂移不会改变按住状态；松开、取消触摸、切到后台或暂停都会释放输入。
- 街机难度每命三格生命；经典与硬核均为一击倒地。三种模式都以三条命开始，街机/硬核有两次续关，经典有三次。死亡丢失当前特殊武器，其余库存保留，恢复基础步枪。检查点重新连接时保护2.5秒，过关补一命（上限五命）和两枚手雷。
- 手雷爆炸清除附近弹幕。武器无限弹药，拾取后入库、不强制换枪。连杀加分，续关扣 2000 分。
- 宿主暂停冻结模拟与计时；继续时恢复战场键盘焦点。重新开始遵循宿主保留角色/重新选择的约定。

## 六种武器

| 字母 | 名称       | 玩法                     |
| ---- | ---------- | ------------------------ |
| P    | 提示词步枪 | 基础直射                 |
| S    | 发散思维   | 五发扇形散射             |
| M    | Token 洪流 | 高速连射                 |
| L    | 思维链激光 | 贯穿多个敌人             |
| F    | 温度拉满   | 旋转火球、波动覆盖与穿透 |
| H    | 深度推演   | 自动调整弹道追踪目标     |

DeepSeek 娘以追踪弹开局，GPT 娘以速射开局，Claude 娘以一层护盾开局。这些数值只是虚构游戏设定。

F「温度拉满」发射旋转推进的独立火球，不再是短程连续火焰。火球沿八方向瞄准轴作圆周偏移，具有波动覆盖；命中判定使用同一真实位置，每枚火球对每个目标最多造成一次伤害。普通间隔0.24秒、单次伤害2、存活1.15秒；纵深模式沿深度前进并在横向/高度平面旋转。超频照常缩短间隔，换枪不重置冷却。减少动态效果只关闭球面纹理旋转，保留影响战斗的实际轨迹。

武器库与护盾、生命、手雷分栏。P1 用 Q/E 循环已持有武器，数字 1–6 直选；P2 用左右方括号循环，数字键盘 4–9 直选。可点击已解锁武器图标，操作区另有就近换枪按钮；灰色图标不可装备，新拾取武器标“新”。换枪不重置射击冷却，暂停时禁用。

完整装备库在桌面默认展开、手机默认收起。折叠摘要始终显示P1/P2当前武器、护盾和手雷；战场下方的快捷换枪保持可用。展开后仍可查看六个武器槽、限时增益和直接点选。

回血、护盾和手雷自动使用，满额时留在场上；已有的武器也保留给队友或之后使用。武器库跨关保留，共同续关重置为角色开局装备。演练解锁六种武器供比较，战役仍需要实际拾取。

## 三种难度

| 模式 | 生命与续关           | 开局装备                        | 敌人时序                 |
| ---- | -------------------- | ------------------------------- | ------------------------ |
| 街机 | 每命3格生命，2次续关 | 保留角色专长；3枚手雷           | 标准                     |
| 经典 | 一击倒地，3次续关    | 所有人基础步枪；无开局盾；0手雷 | 标准                     |
| 硬核 | 一击倒地，2次续关    | 保留角色专长；3枚手雷           | 弹速、射击与孵化节奏加快 |

经典模式用于隔离原作式生存压力与本作角色专长。角色外观和操作仍保留，但DeepSeek/GPT不会以追踪弹或速射枪开局，Claude也没有开局盾；武器、盾和手雷仍可通过战场补给获得。经典模式不会继承硬核的敌人加速。

部署阶段不显示战斗HUD，避免在角色尚未选择时展示默认DeepSeek武器、普通难度生命或其他过期信息；出击后再按实际角色、队伍和难度显示HUD。

## 补给载具与增益

飞行胶囊沿小范围航线移动，补给箱固定在路线旁；它们都有独立耐久，射击或手雷击破后才释放内容物。横向/纵向道具会落地，也会被运输平台或传送带带动；掉入深坑会失去该次补给。补给箱打开后留下空箱，不能重复刷取。基地的补给节点由纵深弹丸击毁，内容物送到前景，横移领取；它们不参与必需核心的门禁计数。

| 增益     | 实际效果                                           | 限制                                 |
| -------- | -------------------------------------------------- | ------------------------------------ |
| 算力超频 | 12秒内射击间隔缩为65%，适用于所有武器              | 换枪保留；原有射击冷却不重置         |
| 沙盒力场 | 6秒免疫弹丸、接触和危险区伤害                      | 不消耗普通护盾；不阻止坠落           |
| 全量清理 | 清除附近普通敌人与弹幕，对正在交战的Boss造成20伤害 | 不击破基地必需核心，不打开其他补给箱 |

增益只属于实际领取者；限时增益不叠加，同类剩余时间不超过一半时才自动领取并刷新，否则留给队友或之后使用。暂停、菜单与结算不消耗时长，跨关保留剩余时长，阵亡和共同续关清空。武器库下方显示秒数与进度条，触屏操作旁也显示当前增益，避免战斗中向上滚动查看。

| 关卡         | 守关者       | 核心机制                         |
| ------------ | ------------ | -------------------------------- |
| 提示词登陆   | 429 限流闸门 | 扇形请求弹幕                     |
| 已读不回工厂 | 已读回执机   | 高低外围节点、屏障解除与主核心   |
| 上下文瀑布   | 上下文吞噬者 | 留出安全列的记忆碎片弹雨         |
| 幻觉高架桥   | 引用缝合怪   | 假桥核验、左右交叉火力           |
| Token 熔炉   | Token 焚烧炉 | 低位弹列与移动落火柱             |
| 智能体叛乱   | 递归调度器   | 成对节点对齐、召唤无人机与主核心 |
| 对齐防火墙   | 拒绝服务堡垒 | 带可穿越窗口的弹墙               |
| 最终生成     | 幻觉之母 · Ω | 孵化节点、三心核保护与组合弹幕   |

Boss 有三个血量阶段、思考装甲与核心暴露窗口。红色预警线与实际发射共用攻击描述。地面小兵、跳跃怪、无人机、炮台和狙击手提供沿途压力；高路放置武器、护盾和补给。

终关进入神经巢穴后，三个孵化节点会周期生成幻觉幼体，幼体总数受上限约束。终战入口保持锁定，直到三个节点全部关闭。进入战区后，三颗推理心核分别位于地面和高台，仍存活时幻觉之母本体完全免疫子弹、激光、火球、手雷与清场道具；心核全部破坏后，才进入原有三阶段装甲暴露和七种攻击组合。Boss演练也保留三心核阶段。

独立 **关卡演练** 可选择八个目标、六种武器，以及「直接挑战 Boss / 从关卡入口开始」，沿用实际伤害，可以重新挑战。演练不会提交战役通关成绩。它提供学习入口，不降低战役难度。

## 实现与验证

规则使用 60 Hz 固定步长，弹丸用线段碰撞避免穿透，状态更新不修改传入对象。视图使用 Vue + SVG；Boss 由 GPT Image 生成的 4×2 透明图集分格显示。背景、角色、敌人与音效来源见 `packages/assets/rewrite/README.md`。

现有内容完善版本：90项规则测试、88项桌面/手机短流程、12项完整战役、类型检查、lint及生产构建通过。街机/经典/硬核 × 单/双人均在桌面和手机通过真实键盘完成八关、终关三段结构、宿主结算及重开；完整流程约11.2分钟。经典模式专项覆盖中性开局、三次续关、敌人时序边界和重开配置保留。

证据边界：三种难度的单人/双人均有合法输入完成八关的规则回放，也已在桌面与移动浏览器通过真实键盘重放到宿主结算。规划器利用精确规则信息和未来动作搜索，这证明流程可通，不代表真人平均难度或优于其他游戏的主观体验。旧的无敌 Boss soak 只用于隔离弹道/阶段检查，不再充当完整通关证据。声音、持续运行和触屏契约已有自动证据；真人主观手感及用户明确后移的其他关卡范围仍不能由自动测试证明，见 `docs/games/rewrite-fidelity-audit.md`。

角色现有 42 个新动作单元：每人四个奔跑姿态、团身跳跃、真实卧倒，四向上/下瞄准，以及三种背向迈步与低姿态。动画使用模拟时钟，暂停冻结；跳跃翻滚遇射击或瞄准停止，减少动态效果保留必要姿态而关闭循环、翻滚和枪口闪光。武器/补给九种图标和敌人/机关六种图像直接用于战场，不是仅存放在素材目录。

## 声音与配乐

八关各有独立的程序化音阶、低音走向和节拍，Boss战会加速并增加低音声部；纵深机房按房间改变旋律偏移。配乐由60Hz模拟时间驱动，不使用独立计时器，因此暂停、切到后台或结算时立即停止，恢复后从当前战斗时间继续。

六种武器具有不同合成音色：步枪短促下降、散射双层低频、速射短脉冲、激光长扫频、火球低频双声部、追踪弹上升回落。跳跃、受击、爆炸、拾取和过关保留独立反馈。声音按钮同时控制音乐和效果音；关闭后清空所有活跃声部。

同时发声上限为24，避免速射、爆炸和音乐叠加时持续创建音频节点。浏览器只读状态验证音乐拍点随模拟推进、暂停清空、恢复重启、静音后不再生成声部；减少动态效果不改变音频节奏。

声音开关旁提供音乐和效果两个独立滑杆，默认音乐0.55、效果1.0。任一滑杆归零时不创建对应音频节点；调整会停止旧声部并按新音量继续。设置随宿主重开保留，关闭声音时滑杆禁用但数值不会丢失。

## 战斗反馈与渲染

受击和爆炸会依据模拟时间产生轻量镜头震动和短暂颜色闪光。反馈由现有命中特效计算，不修改碰撞、伤害或物理时间；相同状态得到相同位移。开启减少动态效果后，震动和闪光均为零。

横版与纵向场景只将镜头附近的玩家弹丸、敌弹、手雷和特效交给SVG渲染，世界模拟仍保留完整对象。激光使用更大的预留边界，避免长光束在屏幕边缘突然消失。战场提供只读模拟/渲染计数，浏览器回归确认渲染数始终不超过模拟数。

动态召唤物在死亡后从模拟数组清理：终关幼体、基地Boss递归无人机不会因长时间反复生成而持续增加每帧克隆成本。关卡原生敌人和结构目标仍保留其死亡状态，计分、掉落、回放与结算不变。

持续运行测试覆盖两分钟反复孵化与清理、150秒递归无人机召唤与清理，以及100秒超频速射。幼体和无人机数组维持在“原生目标＋至多1个当前召唤物”，速射弹丸上界为13，所有坐标和生命周期保持有限数值。

## 独立横向路线与运输平台

五个横向关卡不再使用固定间距的共用生成模板。每关有三段区域提示和独立编排的地形、敌人及补给：

- 登陆：海滩推进、树冠高低分支、桥头炮位；高路可拿护盾，低路推进较快。
- 幻觉高架桥：真假桥核验、两座横移台与一座升降台；上层与地面路线交错。
- Token 熔炉：三段顺/逆传送带、周期炉口、上层冷却管与升降台。
- 对齐防火墙：高低交叉炮组、两座升降台、地面跳跃怪与高台狙击手。
- 最终生成：真假桥、运输平台、传送带、炉口和高低火力的组合路线。

发光紫边与方向箭头标识移动平台，金色箭头标识传送带。站立或卧倒都会随脚下支撑移动，跳跃后脱离；双人分别处理运输，同一平台不会重复推进。画面和碰撞共用 `platformAt`，按模拟时间计算，暂停时完全冻结。自然场景高台复用草沿平台图，工业场景使用金属结构。

移动台是可选路线的一部分；地面断口仍能通过普通跳跃越过。检查点只落在静态、非传送带地面内，并向边缘内缩，避免在坑边着陆时把重生点留在身后深坑。

## 上下文瀑布：纵向攀升

第三关现为 48 米记忆塔。24 次两米高跳跃沿折返路线向上攀升，侧面炮台、狙击手和无人机提供交叉火力；12、24、36 米处的缓存台保存复活坐标并提供恢复。掉到最近缓存高度七米以下会失去一命，从缓存重新连接。顶部是独立守关战区，抵达最右边不能跳过攀升或 Boss。

镜头在攀升时追随高度，在守关战时固定到顶部战台，避免 Boss 与状态栏重叠。敌人激活、子弹存活边界、危险区与预警均使用世界高度；高处战斗不会复用地面零高度。演练中可从塔底练习整段路线。

## 本地双人协作

选择「双人协作」，选好 P2 角色，再点击角色卡让 P1 出击。两位玩家在同一浏览器中合作，不需要登录或网络房间；目前不包含远程联机。

| 玩家 | 移动 / 瞄准 | 射击              | 跳跃              | 手雷              | 定点瞄准              |
| ---- | ----------- | ----------------- | ----------------- | ----------------- | --------------------- |
| P1   | WASD        | J                 | K / 空格          | L                 | 左 Shift              |
| P2   | 方向键      | 逗号 / 数字键盘 1 | 句号 / 数字键盘 2 | 斜杠 / 数字键盘 3 | 右 Shift / 数字键盘 0 |

触屏提供并排的 P1/P2 独立方向盘及动作键。单人仍保留方向键别名；双人模式才把方向键分给 P2。标准手柄按索引分配给P1/P2，可与键盘和触屏混用。暂停、失焦和切换页面统一释放持续输入，跳跃和手雷的按下边沿不会在暂停期间积压。

每人各自三命、武器、护盾、手雷；无友军伤害，得分及续关共享。街机/硬核共享两次续关，经典共享三次。补给只给实际拾取的一人。两人都离线才结束本次尝试。队友至少还有两命时，可通过 HUD 的「为 P1/P2 分出一命」消耗一命使离线玩家重新连接；过关也会让离线队友获得一命。普通阵亡优先在存活队友附近的安全平台复活，否则使用自己的缓存点。

水平距离限制在同屏范围内；攀升领先超过一层时先等待队友，掉出队友下方七米会损失一命。所有存活玩家到达入口才开启 Boss 区。Boss 初始血量为单人的 1.6 倍，瞄准攻击交替选择存活玩家，预警使用同一目标。世界和敌人每帧只更新一次。

新增验证包括输入/武器/手雷隔离、存活队友继续战斗、借命边界、共享续关、共同入场、正常伤害与完整敌人下双人攀到塔顶。浏览器通过实际按键完成坠落离线→借命重连、双人击败首关 Boss→同队重开；触屏模拟验证按钮完整处于控制区内，避免仅检查页面没有横向滚动却漏掉裁切。

## 纵深基地：第二关与第六关

第二关有四间机房，第六关有五间机房，最后一间为正面 Boss 战。每间普通机房都必须击破三个安全核心才能让能源屏障断电，然后主动向前移动到出口，才会进入下一间。通电屏障阻挡前进并造成伤害；跳跃或力场不能越过未解除的屏障。前排炮台可能挡住后面的核心；激光能贯穿前排目标。高位核心需要跳射，追踪弹也会修正高度。

基地操作与侧面战场不同：A/D（或左右方向键）横移，W/上方向键前进，K/空格跳跃，S/下方向键卧倒，J开火；P2沿用方向键与逗号/句号/斜杠。触屏上键与两个上斜键分别向前/斜前推进，跳跃保留独立按钮。屏障位于深度3，出口位于11；前进会改变角色投影、子弹与手雷出发点、敌人瞄准及命中位置。敌弹从前或后穿过玩家所在深度时都进行插值碰撞，双人只命中路径上先碰到的一人。

清除核心后仍有剩余敌人，玩家可先领取前景补给、清理弹幕再前进。双人必须所有存活队员到出口才转场；已离线队员不阻塞推进。进门重置前景位置，死亡重连回到当前房间入口，不恢复已毁核心。

第二关终端由两座不同高度的外围节点保护，必须逐个击破。第六关终端由四个节点构成两组相向运动，成对接近到同一横向位置时暴露；同组另一个被毁后，剩余节点保持暴露。绿色圆环表示可伤害，橙色虚线表示保护，判定与图示调用同一个规则函数。外围仍存活时，主核心对普通射击、激光、手雷和清场道具均免疫，不会被磨血跳过阶段。外围全毁后继续原有主核心三阶段战斗。

每间机房都提供新的补给；过门补一枚手雷。第六关有子智能体敌人，终端守关者会继续召唤增援。双人仍各自持有装备和生命、共同拆除核心，基地横移不使用横版同屏距离限制。三位角色使用 GPT Image 生成的独立背向射击图集；横向/纵向关卡保留原有形象。

验证证据：四种组合（两个基地 × 单人/双人）均在正常伤害、原始敌人血量、有限生命下，通过规则输入完成整段基地和 Boss；不是无敌 soak。浏览器通过真实按键或触屏完成屏障接触、跳跃、拆除首间防线、主动推进进入第二间，并检查组合节点的暴露状态和主核心保护。完整战役证据见下节；真人初见难度仍未由自动回放证明。

## 连贯通关与重开

六份输入记录保存在 `tests/replays/`，格式、限制与重新生成方式见该目录的 README。普通测试快速重放街机/经典/硬核 × 单/双人六种组合；完整浏览器重放从选角开始，依次击败八个守关者、点击过关按钮，最终检查宿主结算以及重开/重新选角。

- 普通回归：`npm --workspace @moecore/game-rewrite run test` 与 `npm --workspace @moecore/web run test:e2e -- rewrite.spec.ts`。
- 完整浏览器流程：先 `npm run build`，再运行 `npm --workspace @moecore/web run test:e2e:rewrite-campaign`。独立配置收集十二种桌面/手机组合，本机约需11分钟；默认 CI 保留短流程和快速规则回放。
- 关卡或战斗规则有意变化后，可运行 `npm --workspace @moecore/game-rewrite run record:campaign` 重新规划输入。先调查失败，不通过改血量、位置或直接设置结局来让回放变绿。

宿主会在新对局时重建组件。游戏现在只在当前窗口记住最近的出击配置，以 `attempt` 区分重开与新进入：「再来一局」沿用角色、队伍、难度、演练设置、声音开关及音乐/效果音量；「重新选角」显示角色选择。它不会保存或恢复旧的战斗状态，也不会在重新进入游戏时自动续打。
