# AI 娘闯关

五关连续横版动作游戏。选一位 AI 看板娘，向右移动，跳过地面缺口，躲避敌人的子弹并射击。前四关到达出口即可进入下一关；第五关需击败紫色守关敌人。它发射子弹后会短暂露出弱点。

| 关卡       | 变化                                   |
| ---------- | -------------------------------------- |
| 开机热身   | 学习跳跃与射击，在两个位置选择能力     |
| 已读走廊   | 炮台先“已读不回”，开火后才短暂允许反击 |
| 上下文高路 | 地面过期区清空护盾；高路可绕开并补缓存 |
| 弹幕加班   | 更宽的缺口、更快的回信，低弹与高弹交替 |
| 幻觉大王   | 核查假桥；大王每轮回话只露一次破绽     |

## 操作

- 键盘：A / D 或左右方向键移动，空格 / K / 上方向键跳跃，J 射击。
- 触屏：画面下方提供左右、跳跃和射击按钮；左右与射击支持按住。
- 宿主暂停时，物理、射击和有效对局计时停止；宿主重开会从第一关创建新的对局。失败时可直接重试本关，保留此前选择的能力。

## 风格与能力

| 角色        | 游戏内风格 | 开局效果           |
| ----------- | ---------- | ------------------ |
| DeepSeek 娘 | 推演       | 子弹更容易命中敌人 |
| GPT 娘      | 联想       | 射击速度更快       |
| Claude 娘   | 守护       | 开局多一层护盾     |

第一次能力选择提供三发子弹或护盾，第二次提供快速射击或穿透子弹。角色数值只是这款非官方同人游戏的虚构设定，不对应真实模型能力。

地面敌人会移动，粉色炮台会射击；高处的星星每颗提供一层护盾。第二关起，部分炮台在开火前有护盾，玩家要躲过一发“回执”后趁回信窗口反击。第三关的地面过期区会清空护盾，没有护盾时扣生命；走高路能绕开并收集星星。第五关的虚线桥不承重，射击能提前核查并让它消失。幻觉大王低、高位弹交替攻击，每次开火后只接受一次有效命中。

第四关炮台把“追加需求”变成低、高位交替的回执弹：低弹要跳，高弹留在地面。关卡会逐渐要求读弹道、取高路、从边缘起跳和核验假桥。文字提示直接说明危险与应对，不依赖玩家先懂 AI 梗。三位角色数值、护盾与“上下文”关系仍是虚构玩法。

五关使用各自的 GPT Image 远景，三位角色使用已有形象延展的待机、奔跑和射击位图；移动回执怪、打印机炮台与幻觉大王也使用独立图。平台沿用项目生成的薄荷草沿素材，碰撞仍由规则数据决定。子弹、护盾、星星、进度与反馈特效由 SVG 绘制。游戏提供可关闭的 Web Audio 短音效，不需要音频文件。

原始生成稿、压缩后的运行图和来源见 [`packages/assets/rewrite/README.md`](../../packages/assets/rewrite/README.md)。当前不是逐帧动画，空中仍复用待机姿态；真人手感、手机实机性能和最终美术质量仍需检验。
