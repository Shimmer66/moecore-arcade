# 战斗吧，大肥鱼

白饭我吃，拳头你挨。原名“DeepSeek 娘：推演对决”，入口与存储 ID 仍为 `duel`。

入口：`/#/games/duel`。六名角色的离线横版格斗游戏，现有快速对战、三站连战、练招房、同机双人对战和3v3车轮战。当前数值仍需真人试玩调整。

### 逐步练招课程

进入练招房后，在“练什么”中选择课程，自动设置距离、木桩和起始五格气。战斗画面下方显示当前按键、提示和重试按钮，完整步骤在课程卡片中查看。

- **三下端走**：J轻拳 → M轻脚 → K近重拳，要求三次命中连续。
- **上天也要挨揍**：S＋K挑空 → 跳跃追击 → J空中拳 → K空中重拳。
- **这顿越吃越大**：I一阶命中 → 特写前段R升级 → 二阶命中后T终结，检查真实升阶取消。
- **角色招牌课**：DeepSeek吃饭回血、GPT接人摔投、豆包拍回自己的回旋气泡、甲方指令投落地、提示词仙人符阵减速、断网大爷断网后普通攻击。

课程根据实际伤害、抓取、回血与反弹结果推进；空挥、被挡、次序错误、断连或错过窗口会提示原因。重试保留本次练习已通过的课程，新开练习重新计数。课程期间固定木桩和能量设置，切回自由练招即可自行调整。按键教程使用P1布局；手机可用对应触屏按钮操作。

GPT 的 F接人和 O普通投已接入独立八帧接投图集：张手、下蹲接人、托住、抬起、下摔和收势。被抓角色随动作升降，结算伤害后显示倒地姿势；接投120、普通投100伤害，前8帧拆投窗口保留。图集随GPT预加载，图片失败时沿用备用姿态。生成提示词及校准记录见 `packages/assets/duel/grapple-motion/`。

DeepSeek 的 F白饭已接入独立八帧招牌动作：端碗、护饭、夹饭、塞饭、咀嚼、吞咽、举空碗和收碗。首次按F仍按原规则自动吃完；饭被抢后，持碗者按F进入吃饭动作。第36模拟帧结算生命+40和能量+20，画面在下一渲染帧进入举碗反馈，避免血条晚于表情。动作图自带饭碗，播放时隐藏旧矢量浮碗；其他角色持有白饭时继续显示通用饭碗。素材及提示词见 `packages/assets/duel/signature-motion/`。

豆包的 F回旋气泡也使用独立八帧招牌动作：查看退回气泡、蓄力甩锅、离手、随挥、装作无事、发现返回、护脸和尴尬恢复。第18帧生成真实投射物时，角色图切到空手随挥，避免图集气泡与投射物重叠；气泡开始回程后按距离显示发现/护脸姿势。玩家出拳、跳跃或蹲下时立即让位给真实动作，K重拳的有效帧和反弹规则没有改变。

甲方的 Y合同锁人使用独立八帧动作：递合同、逼签、伸手锁人、合同贴身、抬起、盖章、压下和举合同收势。抓取后对手从18高度平滑抬到62，第9帧红章结算180伤害；伤害后对手显示倒地姿势，随后随压下动作落地。指令投仍不可用O拆投，只能在第6帧抓取生效前躲开或打断。普通O投和F退回重做不使用这套动作。

提示词仙人的 U飞符和 F慢鸡符阵共用独立八帧动作：抽符、敲键盘、空手发符、掌势收招，以及蹲下画阵、落符、结印启动、抱臂收势。飞符仍在第16帧生成；符阵在第22帧落地后先显示六帧旋转键盘结界，再激活45伤害与90帧减速。EX飞符同时生成强化飞符和符阵。减少动态效果时结界固定角度，不影响判定。

断网大爷的 U拉线和 F断网共用独立八帧动作：拿插排、甩网线、网口命中、后仰拉人，以及检查插头、蹲下抓线、拔线命中、离线拳架。普通U造成70伤害并把目标拉到64距离，EX U造成100伤害并只让对手断网90帧；F造成25伤害并让双方断网150帧。断网状态显示划线Wi-Fi标记，普通拳脚、投技、闪避和脱身仍可使用。

现有连段输入已收敛：轻拳、第二拳和蹲轻拳命中或被挡后，可以取消到变招、挑空或大招；GPT、甲方、提示词仙人和断网大爷还可直接接U技能。DeepSeek的U是反击架势、豆包的U是慢气泡，不构成轻拳真连，二者改用V变招衔接。轻脚、蹲轻脚和近重拳原有取消保持。方向指令完成后8输入帧内按拳脚仍可识别，特殊技可在收招前12个后续模拟帧提前缓存。普通拳脚保持原12帧缓存，打空不能提前取消，也不会在长收招后自动补出第二拳；远重拳、扫腿和挑空继续作为明确的连段终结。

有效的普通技→角色技取消会在角色位置闪出取消火花。轻击保留较小命中特效；近重拳、重脚、扫腿、挑空、空中重击、击飞、投技等强打击使用更大的命中火花、更低沉的反馈音和约90毫秒多方向镜头震动。勾选“减少动态效果”或关闭“镜头震动”后不移动画面，不改变命中停顿及判定。

命中窗口内，操作区会给当前真正可执行的后续按键描金：普通拳脚、U/V、I、H、快速MAX、击飞和跳跃追击会按当前动作显示。能量不足、技能冷却、断网或同类投射物仍在场时不高亮。DeepSeek和豆包的轻拳提示V，另外四人提示U；P2触屏区使用相同规则。

防守窗口也使用实时提示：格挡硬直中有50能量会高亮C滚开和P脱身，有100能量再高亮G防反；受击或浮空且本回合未脱身时高亮P。普通攻击被挡后只显示实际允许的轻拳续压与U/V/I取消，不会错误高亮必须命中的K/N/H。

防御槽低于角色容量25%时由“防御”改为橙红色“嘴硬告急”，归零显示“嘴硬失败”。当前容量下，轻拳连续格挡10–14次、重击4–6次、技能7–9次、一阶大招3–4次、终结技2次会破防；没有普通招式能够一次打满防御槽。

普通投、甲方F退回重做和GPT接人抓住对手时，防守方头顶显示O/P2数字5以及剩余拆投帧数，对应投技按钮同步描金；窗口结束后显示“拆投窗口已过”。甲方Y合同锁人显示“合同锁死·不可拆”，不会高亮投技按钮。双方提示会向各自外侧错开，靠近场边时自动改向场内，避免重叠或裁切。

普通致命打击会强制败者进入倒地姿势，双倒则双方同时倒地。回合规则仍在命中帧立即结算，但K.O./DOUBLE K.O./时间到面板延后12帧约0.2秒出现，先完整展示最后一击火花与倒地，再弹入结算；开启减少动态效果时保留延迟但关闭面板缩放动画。
练招房K.O.显示“1秒后恢复站位”，不显示不参与结算的0:0比分；正式对战与3v3继续显示真实胜场/剩余队员。

声音仍由本地WebAudio即时合成，不依赖额外音频文件。轻击是短方波，强打击/投技为双层低频冲击，格挡为三角波，取消与MAX使用上扬提示音，反击为双层高频，气泡、跳跃、落地、大招和K.O.各有独立包络；总增益受宿主音量控制，关闭声音时不创建音频节点。

非练习对局进入最后10秒时，中央计时改为橙红色“最后关头”，每秒播放逐渐升高的短提示音；最后3秒使用更强方波并脉冲显示。暂停和大招特写不推进计时，练招房不触发；开启减少动态效果后保留颜色与声音但关闭脉冲缩放。

生命条包含浅色伤害残影：实际生命在命中帧立即更新，残影保持18个模拟帧约0.3秒，再以每帧12生命追赶。连续受击会重新计时，回血、换人和回合重置立即向上同步；开启减少动态效果时残影与实际生命同帧变化。

二连以上的连击框显示连击数、累计伤害、最新一段伤害、当前段缩放百分比和“累计伤害/保护上限”。普通连段依次为100%/85%/70%/55%/40%，后续保持40%；大招最低70%。达到当前350/500/600/700上限80%时改为暖色，提示即将触发连段保护。

390px以下布局会把连击框从场地顶部26%下移到38%，并缩小明细文字；格挡帧差保持在39%。两种反馈都位于HUD下方和场地内部，不遮挡血条，也不会制造横向滚动。

练招房在招式被挡后显示实际帧差与先动方，例如“被挡 -5·对手先动”。帧差直接由当前角色、EX状态、超必杀层级、命中招式段和剩余收招计算；气泡等独立投射物不显示容易误导的角色收招帧差。

“重置站位”、新对局、连战加菜和回合交接会立即清除上一段连击框、帧差提示，并把伤害残影同步到新角色生命；不会在新木桩或下一名队员上短暂显示旧HUD数据。练习累计统计与已通过课程仍按原规则保留。

电脑也使用同一套角色连段。挑战难度更常在自己的轻拳命中后确认：DeepSeek和豆包有25能量且变招可用时接V，GPT、甲方、提示词仙人和断网大爷在技能可用时接U；技能冷却、断网或飞行物在场会回退到普通拳脚。轻松难度更常使用简单轻拳链，不会因难度提高基础伤害或生命。

电脑的空招惩罚只读取难度对应的延迟战场快照。观察到重拳、技能、变招、整活或投技进入收招后，挑战难度更常在真实轻拳范围内按轻拳，距离较远则先冲刺；轻松难度因观察延迟和较低确认率更常错过。它不会读取玩家当前按键，也不会在攻击有效帧或动作结束后继续判定为空招。

近重拳不再使用统一66距离判断，而是采用各角色已有的实际近拳距离70–86。J→M造成小幅推距后，K仍能稳定选择近重拳，不会突然切成远重拳导致三连掉段；超过角色近拳距离1单位时仍会正确使用远重拳。当前实测通用三连伤害107–148、角色二连95–140、近重拳接V为132–189、挑空追击统一185，差异保留角色速度、范围与控制能力，没有强行拉平成同一伤害。

普通技被挡后的实际帧差均为负：轻拳统一-5，轻脚-6至-10，近重拳-7至-14，远重拳-12至-17，重脚-11，扫腿-9。防守方结束硬直后有明确反击机会；进攻方要继续压力必须在接触取消窗口内选择U/V/I/MAX等合法路线并承担资源或冷却。

## 五种模式

原创互动还包括豆包气泡命中 DeepSeek 后的“深度冒泡”。这些反馈由实际命中驱动；格挡不会触发变包，倒地结束恢复正常身体。练招房可重复体验，详见[原创互动记录](../../docs/games/deepseek-duel-memes.md)。

新增“缓存命中”（DeepSeek 同回合再次反击同一招）、“已读已堵”（豆包气泡命中 GPT，嘴堵了耳朵继续输出）、“版本回滚”（GPT 变招完整打空或被挡后撤回视觉残影）与“嘴硬结算”（败者把失败牌翻成战略性休息）。六张新图片已用于战斗和结算，回滚不返还资源，嘴硬不改真实比分。练招房新增“反复重击（练反击）”木桩，每 1.5 秒尝试一次重击。

### 3v3：三个人，一张饭卡

- **编队与排序**：每队选三人，选到同队已有角色会交换位置；上下箭头调序，两队可以镜像。再战保留编队与控制方式，“重新编队”回到选队页。已选角色素材在开打前预热。
- **败者接力**：一战75秒，败者退场、下一位满血上场。胜者留场并保留血量，按剩余时间回复`min(180, 60 + 剩余整秒 × 2)`，最多回满；时间到获胜回60。最终整场结束不再回复。
- **双倒与时间平局**：当前双方一起退场；若一方还有后备、另一方耗尽，仍有队员者获胜。双方同时耗尽算整场平局。普通时间结束按剩余血量决胜，败者即使还有血也退场。
- **共享能量**：两队分别继承上场者剩余能量。先锋上限300、中坚400、大将500。MAX/EX动作状态、技能冷却、断网、减速、防御损耗和输入在交接时清除；场上的飞行道具、符阵、饭碗和抓取不带入下一战。
- **整场胜负**：打光对方三人才赢，不受普通模式“两胜/三回合”限制。最多进行五战，也可以同一角色一穿三。HUD展示三人队列与退场状态，交接显示下一人和胜者回血数。
- **结算**：统计全队总伤害、最高连击、剩余人数及出战场数；逐角色累计伤害和击败人数用于MVP文案。本地双人明确显示P1或P2队伍获胜。角色教学提示随实际出场者切换。

连战补丁：续杯 Token（下一站起始能量 +25）、水冷大脑（技和变招冷却缩短 20%）、轻量部署（步行和空中移动速度 +12%）。同一补丁不可重复选择；决赛缓存分身公开获得 25 起始能量。重新连战清空补丁，快速对战不继承。

难度有轻松、标准、挑战，影响人机观察延迟、决策节奏与连段选择，不改变基础生命与伤害。练招房的“会还手”使用所选难度。

**双人对战**：P1 自选角色，P2 在“P2 角色”中选择，可镜像对战。与快速对战同样为 75 秒/回合、最多三回合；不启用 CPU。再战保留双方角色和双人模式，换角色回选角。两套触屏区域支持独立指针，暂停、失焦、回合转换均清空两方输入。

## 操作

A/D 或左右方向移动；W/空格/上方向跳跃，空中再按一次为二段跳；S/下方向蹲下；H 或触屏「冲」冲刺，无方向输入时向面朝方向冲刺，也保留双击方向。空中冲刺每次腾空限一次，落地恢复；冲刺不提供无敌，起手 4 帧后可接拳脚或跳跃。
跳键前6个模拟帧内松开为小跳，持续按住为普通跳。先蹲后8帧内起跳，或冲刺中起跳，为大跳；再早松开跳键则为高速小跳。大跳/高速小跳保留起跳方向惯性，空中方向可小幅修正；二段跳和挑空追击不被短按截断。四种地面起跳已验证高度约51/150/63/233逻辑单位，练习输入区显示类型。
J 轻拳、M 轻脚、K 重拳、N 重脚、L 按住防御、U 技能、V 变招、P 脱身、O 投技与拆投、I 满能量大招。Esc 暂停。
M 轻脚起手快，站立/下蹲/空中都有独立判定；地面命中后可接重拳/重脚。N 站立前踢、下蹲扫堂腿、空中砸落。蹲＋J 是低位拳，蹲＋K 保留挑空。对手落地且位于角色实际近重拳距离70–86以内时，K自动选择近重拳；超过各自范围时使用远重拳。四种空中拳脚都有独立帧数、距离与伤害。下蹲、蹲防、蹲拳和低踢的图片与低位受击区域统一，脚底贴地。
触屏提供全部独立按钮，支持同时移动与跳跃/攻击。按住攻击不自动连打。

普通拳脚预输入保留12个模拟帧（约200ms）；特殊技、变招、跳跃等指令保留按键当帧及随后12个模拟帧。缓存保存按下时的方向与蹲姿，命中停顿期间不消耗时限。快速松开蹲键仍会打出已输入的蹲重。键盘与触屏都有按下反馈，暂停和失焦清除按住状态。

### 连续动作衔接

- 跳跃和普通拳脚在同帧输入时，可同帧起跳并出空中招式；等落地或命中停顿结束时，缓存会一起保留跳跃与攻击。
- 按攻击后2帧内补跳或补蹲，可把尚未进入有效判定的起手转换为跳攻/蹲攻。同帧按键先后顺序不再决定是否站立出腿；超过起手容错阶段仍需遵守正常收招。
- 空中轻拳20帧、轻脚18帧、重拳27帧、重脚29帧、击飞30帧后恢复为空中移动，可再次出招，不再卡在攻击姿态直到落地。空中轻拳命中还能接轻脚，轻攻击命中接重攻击的原有规则保持。
- 空中拳脚落地恢复由10帧缩短为6帧，最后2帧可接普通拳脚、跳跃或冲刺。落地显示缓冲蹲姿，实际受击区与蹲姿对应，真实受击硬直不能利用这条规则逃脱。
- 空中或同帧起跳攻击不会被之前记住的地面搓招替换为无法发动的地面技能。二段跳次数耗尽时，额外跳键不会吞掉合法的空中拳脚。

前两段轻击有效命中后，10 帧窗口内按 H 可消耗 15 能量取消收招并冲刺追击，之后可再接 J；被挡或打空不允许这种取消，普通自由状态冲刺免费。GPT 技能第一段命中后，8 帧内可花100能量接 I 大招。伤害衰减、普通五连/350伤害与MAX八连/500伤害保护生效。

## 三阶超必杀与防御反击

- **一阶 I / 二阶 R / 终结 T**：普通释放分别消费100/200/300能量。MAX剩余至少240帧时，一阶消耗240帧；二阶/终结消耗全部MAX时间并分别花100/200能量。
- **超级取消**：特殊技/变招/反击接触后可接大招，合法击倒会延续衔接；已经触发普通连段保护的击倒不能借此重开连段。
- **升阶取消**：一阶升级二阶、二阶升级终结各追加100能量，一阶直升终结追加200。大招接触后12模拟帧内可升级；最终命中特写前36个显示帧（0.6秒）也接受升级，只接收施术方输入。空挥、对手KO、同阶及降阶取消均不可用。
- **连段保护**：二阶预算最高12击/600伤害，终结12击/700；衔接保持原连击与伤害累计。多段终结达到伤害预算后，剩余段不再造成伤害，最终段仍完成演出和终结效果。资源与预算不返还。
- **指令**：双正摇＋两拳为二阶；`↓↙←↙↓↘→＋拳`为终结，换边镜像。R/T是同规则的快捷键。
- **G击飞/防反**：平时免费，地面/空中各有判定；也可同时按重拳＋重脚。处于格挡硬直时花100能量发动防御反击，前10帧保护、4帧起手、总长35帧；空挥收招可被惩罚。缺气的防反输入不会在格挡结束后变成免费击飞。受击硬直不能用防反逃脱。
- P2使用引号键二阶、等号键终结、分号击飞/防反。P1高级触屏按钮位于“进阶”展开区，特写中显示可点击升级按钮；P2触屏区也有对应按钮。

## 新增动作图集

六角色每人新增16帧，共96帧，位于`packages/assets/duel/advanced-motion/`。覆盖C翻滚、G站立击飞、格挡后G防反、空中G击飞；甲方推文件夹、仙人顶键盘、大爷推插排，各自保留角色装备特点。豆包沿用短发红围巾形象。

`AdvancedMotionSprite.vue`与`advanced-frame.ts`已接入局内，根据真实起手/有效/收招时间选择帧。图集按实际透明轮廓裁切并校准脚底，不把下蹲和滚动姿态拉伸成站立高度。减少动态效果跳过倒立帧，素材请求失败可回退原动作。

同目录提供`preview.html`逐帧预览和`prompts.md`生成提示词。原始PNG字节未修改，仙人重复键盘的修正由内置image_gen完成；运行选用v2。

`packages/assets/duel/normal-motion/`另补六人96帧：站立轻脚、蹲轻脚、空中轻拳、空中重拳各四帧。`normal-frame.ts`保证命中帧出现完整伸展动作，空中J/K不再借用飞踢；空中M使用原快速踢，N选用进阶图集的向下重踢。图片失败可独立回退，预览和提示词也在同目录。

`packages/assets/duel/signature-motion/`已接入DeepSeek、豆包、甲方、提示词仙人、断网大爷各8帧招牌动作，共40帧；`grapple-motion/`接入GPT接人/摔投8帧。剩余美术缺口集中在EX、高阶大招、普通双方投技的更多专用接触帧，不再笼统标记“招牌技未补”。

## 实现

`src/rules.ts` 是无浏览器依赖的固定 60 Hz 状态推进器，只修改传入战局；`src/moves.ts` 定义招式与难度参数，`src/ai.ts` 提供有观察延迟的种子人机，`src/modes.ts` 管理连战与补丁。`DuelGame.vue` 管理输入、宿主事件、SVG 擂台和反馈，`FighterSprite.vue` 绘制可动角色。

已接入原有立绘/表情/大招、战斗关键姿态和六种特效，并新增三人共 72 帧主要动作序列及 9 个下蹲/腿法姿态。`RasterFighter.vue` 结合 `combat-pose.ts` 与 `motion-frame.ts` 按真实动作阶段选帧，使用已校准的脚底锚点和图集 viewport，反向站位与残影同步翻转图片；`CombatEffect.vue` 展示独立战斗特效。旧 `FighterSprite.vue` 仅作图片失败备用，原创梗中的包子变身与道具保留独立绘制。

豆包先在本游戏阵容中登记；共享角色表被消消乐直接用作棋子池，因此不把没有配套消消乐资产的角色加入该池。声音通过 Web Audio 合成；设备有本地中文语音时可以开启台词，否则显示字幕。运行时无外部模型 API 或音频下载。

## 验证

### 加载与性能

`art-loading.ts`根据正常渲染路径预热图片，共享每张图片的进行中Promise与已完成解码结果。仅当图片加载失败才用到的旧图集不再提前解码；改变对战模式或调整相同成员的顺序不会再次解码。

所有模式在战斗素材就绪后再开始倒计时。快速开始时会显示“拳脚热身中”和进度，期间不推进战斗、不缓存误触攻击。损坏图片计为已处理，角色仍走已有回退路径。三站连战按本次实际生成的整队对手预热，3v3按所选队伍预热。

2026-09-30记录的本机生产页单次采样：

| 指标             | 练习：优化前 → 后 | 3v3：优化前 → 后 |
| ---------------- | ----------------- | ---------------- |
| 主动解码调用     | 60 → 27           | 135 → 55         |
| 重复解码调用     | 30 → 0            | 70 → 0           |
| 预热RGBA像素估算 | 188.7 → 169.8 MB  | 408.9 → 346.0 MB |
| 本次准备耗时     | 1813 → 1234 ms    | 2750 → 1524 ms   |

约五秒键盘脚本内，优化后两种模式均无战斗开始后的主动解码，未观察到长任务。390px窗口配4倍CPU减速的独立样本，帧间隔95分位约16.7–16.8ms；练习场仍出现一次52ms长任务。**这些是本机短时浏览器模拟，不能作为所有设备不卡或真机性能达标的结论。** RGBA像素估算不是进程内存/RSS，也不是测得的显存占用。

接入五套招牌图集后于2026-10-01复测：桌面练习/3v3准备1182/1038ms，4倍CPU移动样本1487/1480ms；P95仍为16.7–16.8ms，四个样本均无长任务、战斗中解码或运行时错误。预解码RGBA估算增加到182.4MB/383.7MB，因此仍需真机内存验证；当前没有为了降低估算值而引入换人时按需加载停顿。详见[最新性能记录](../../docs/games/duel-performance-2026-10-01.json)。

加入残血条、帧差、连段明细、K.O.与分层音效后再次运行4倍CPU样本：练习/3v3准备1496/1424ms，P95为16.8/16.7ms，回调P95为0.7/0.8ms；无长任务、战斗中解码或错误。稳定生命状态使用同一残血条对象，不在每个60Hz模拟帧分配新状态。
