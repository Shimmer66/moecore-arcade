# DeepSeek 娘：推演对决

入口：`/#/games/duel`。三名角色的离线横版 1v1 格斗游戏，现有快速对战、三站连战、练招房和同机双人对战。当前数值仍需真人试玩调整。

风格方向为《死神 VS 火影》式高速横版动漫格斗，采用本项目原创 AI 角色与招式。现已支持独立冲刺、二段跳、空中冲刺及“挑空 → 跳跃追击 → 空中轻击 → 重击砸落”，配合冲刺残影、角色起手/出招姿势和弧形攻击轨迹。

- DeepSeek 娘：“拳理服人”三连，前两拳、第三脚，空中攻击也使用飞踢；拳打 GPT 触发“物理省流”，第三脚踢中豆包会把她短暂踢成红围巾包子。保留短窗口反击、后撤延迟斩和专家会诊大招。
- GPT 娘：轻击三段、两段突进；变招可以由轻击命中/被挡接入，命中后再接轻击；综上所述大招。
- 豆包娘：气泡控制距离；变招跃起上勾拳；省字不省拳大招。形象以用户提供的侧分短发、红围巾为准。

## 四种模式

原创互动还包括豆包气泡命中 DeepSeek 后的“深度冒泡”。这些反馈由实际命中驱动；格挡不会触发变包，倒地结束恢复正常身体。练招房可重复体验，详见[原创互动记录](../../docs/games/deepseek-duel-memes.md)。

新增“缓存命中”（DeepSeek 同回合再次反击同一招）、“已读已堵”（豆包气泡命中 GPT，嘴堵了耳朵继续输出）、“版本回滚”（GPT 变招完整打空或被挡后撤回视觉残影）与“嘴硬结算”（败者把失败牌翻成战略性休息）。六张新图片已用于战斗和结算，回滚不返还资源，嘴硬不改真实比分。练招房新增“反复重击（练反击）”木桩，每 1.5 秒尝试一次重击。

| 模式     | 玩法                                                                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------------------- |
| 快速对战 | 自选对手，75 秒回合，最多三回合                                                                                        |
| 三站连战 | 依次面对另外两位角色和自己的缓存分身，每站单回合 60 秒；胜利后选一个独立补丁，生命回满进入下一站；输或平局结束整次连战 |
| 练招房   | 不限时，站立/防御/还手木桩可切换，支持无限能量与重置站位；记录三连、投技、变招和大招四项练习目标                       |

连战补丁：续杯 Token（下一站起始能量 +25）、水冷大脑（技和变招冷却缩短 20%）、轻量部署（步行和空中移动速度 +12%）。同一补丁不可重复选择；决赛缓存分身公开获得 25 起始能量。重新连战清空补丁，快速对战不继承。

难度有轻松、标准、挑战，影响人机观察延迟、决策节奏与连段选择，不改变基础生命与伤害。练招房的“会还手”使用所选难度。

**双人对战**：P1 自选角色，P2 在“P2 角色”中选择，可镜像对战。与快速对战同样为 75 秒/回合、最多三回合；不启用 CPU。再战保留双方角色和双人模式，换角色回选角。两套触屏区域支持独立指针，暂停、失焦、回合转换均清空两方输入。

- P1：WASD 移动，J/K/L 拳/重/挡，U 技能、I 大招、O 投技、V 变招、P 脱身、H 冲刺、F 整活。
- P2：方向键移动，数字 1/2/3 拳/重/挡、4 技能、5 投技、6 大招、7 变招、8 脱身、9 整活、0 冲刺。主键盘数字行和数字小键盘都可使用。

## 三个角色核心梗

按 F（P2 数字9）发动独立整活技能，冷却均为 7 秒。

| 角色                      | 机制                                                         | 对抗办法                                |
| ------------------------- | ------------------------------------------------------------ | --------------------------------------- |
| DeepSeek · 吃白饭的大肥鱼 | 吃饭 36 帧后回复最多 40 生命与 20 能量                       | 吃完前打中会洒饭，回复取消              |
| GPT · 稳稳接住你          | 第 6–28 帧接住正面近处下落的跳跃/空中攻击对手，摔落 120 伤害 | 地面攻击打断，或被接后 8 帧内按投技拆开 |
| 豆包 · 唐包·答非所问      | 回旋气泡打中对手 80 伤害，打空后返回，可误伤自己 50          | 跳过气泡、逼她接回自己的问题            |

来源与原创机制的区分见[本轮检索记录](../../docs/games/duel-meme-research-2026-09-27.md)。这些梗是对虚构 AI 角色的战斗演绎。原技能、变招与梗技能分别计冷却，基本攻击规则不变。

### 双人互坑互动

- **抢饭大战**：靠近饭碗持有者按 O（P2 数字5）抢饭，本次不附加投技伤害。持碗者按 F（P2 数字9）花 36 帧吃掉，获得同样的 40 生命/20 能量回复。原主人打中持碗者就能夺回，即使原整活冷却未结束也能吃回自己的饭。场上同时一碗饭，持有超时、打翻或回合结束后消失。
- **接住过载**：GPT 接人时若撞上额外气泡，或双方正带着饭碗，两人一起摔落；尚未结算的 120 摔投伤害取消，已结算的伤害不回滚。过载本身不追加伤害。
- **包邮到家**：K 重击、蹲重、空中重击的有效攻击帧可以把气泡打回去，也可以救下自己返回的回旋气泡。双方可再次反弹，但不增加气泡伤害、不重置剩余寿命。原发射者被反弹气泡命中后显示“您购买的挨打已送达”。

## 操作

A/D 或左右方向移动；W/空格/上方向跳跃，空中再按一次为二段跳；S/下方向蹲下；H 或触屏「闪」冲刺，无方向输入时向面朝方向冲刺，也保留双击方向。空中冲刺每次腾空限一次，落地恢复；冲刺不提供无敌，起手 4 帧后可接拳脚或跳跃。
J 轻击、K 重击、L 按住防御、U 技能、V 变招、P 清空上下文、O 投技与拆投、I 满能量大招。Esc 暂停。
触屏提供全部独立按钮，支持同时移动与跳跃/攻击。按住攻击不自动连打。

预输入保留 10 个模拟帧（约 167ms），同时保存按下时的方向与蹲姿，命中停顿期间不会消耗缓存时限。快速松开蹲键仍会打出已输入的蹲重。键盘与触屏都有按下反馈，暂停和失焦清除按住状态。

前两段轻击有效命中后，10 帧窗口内按 H 可消耗 15 能量取消收招并冲刺追击，之后可再接 J；被挡或打空不允许这种取消，普通自由状态冲刺免费。GPT 技能第一段命中后，8 帧内可花满能量接 I 大招。伤害衰减、五连击和 350 伤害保护仍然生效。

连点轻击可接三段；GPT 可在轻击命中后接技能。所有角色可命中确认接大招。
防御挡正面攻击，投技破解防御，跳跃躲气泡，蹲＋重击对空。

蹲＋K 挑空命中后，12 帧内可按跳取消后摇并追击；J 命中后接 K 为砸落终结。普通拳命中后也可接重击或蹲重挑空；GPT 重击、豆包变招成功挑空同样可跳跃追击。被挡/打空不会获得追击取消。浮空仍计入原有连击上限，落地进入倒地保护，P 脱身也可在浮空中使用。

变招消耗 25 能量，独立冷却 5 秒。清空上下文消耗 50 能量，只能在受击/格挡硬直中使用，每回合一次：拉开距离、清除敌方气泡并给予短暂保护；倒地、被抓或大招特写时不能用。练招房的重置站位恢复本次练习的战斗状态，但保留已完成目标。

## 对局

双方 1000 生命、100 能量上限，每回合 75 秒。最多三回合，先两胜结束；三回合后比较胜场，同分为平局。削血不致死，同帧互殴可双倒。连段有伤害衰减、350 伤害上限、倒地与起身保护。

暂停、操作说明、命中停顿和大招特写期间，世界与计时暂停。再战保留双方角色并重置整场；换角色返回选择页。刷新不保存对局。

## 实现

`src/rules.ts` 是无浏览器依赖的固定 60 Hz 状态推进器，只修改传入战局；`src/moves.ts` 定义招式与难度参数，`src/ai.ts` 提供有观察延迟的种子人机，`src/modes.ts` 管理连战与补丁。`DuelGame.vue` 管理输入、宿主事件、SVG 擂台和反馈，`FighterSprite.vue` 绘制可动角色。

已接入原有 18 张立绘/表情/大招、DeepSeek 与豆包各 12 张战斗关键姿态、GPT 十二姿态图集及六种独立特效。`RasterFighter.vue` 按 `combat-pose.ts` 切换出招阶段，使用已校准的脚底锚点和图集 viewport，反向站位与残影同步翻转图片；`CombatEffect.vue` 展示气泡、破裂、鲸尾斩、命中、格挡和落地烟尘。旧 `FighterSprite.vue` 仅作图片失败备用，原创梗中的包子变身与道具保留独立绘制。当前为关键姿态切换，尚非完整逐帧动画。

豆包先在本游戏阵容中登记；共享角色表被消消乐直接用作棋子池，因此不把没有配套消消乐资产的角色加入该池。声音通过 Web Audio 合成；设备有本地中文语音时可以开启台词，否则显示字幕。运行时无外部模型 API 或音频下载。
