# 跑道角色搞怪动作

三张全身动作帧由内置 GPT Image 参考原跑酷角色姿势生成，保留蓝发、鲸鳍、尾巴、女仆装和向右运动方向。

| 文件                    | 使用时机                 | 生成提示词要点                                                              |
| ----------------------- | ------------------------ | --------------------------------------------------------------------------- |
| `char-rice-run.webp`    | 吃到白饭后短暂显示       | 参考 `char_run_01.webp`；一边跑一边偷吃白饭，鼓腮、心虚侧眼、尾巴兴奋摆动。 |
| `char-overload.webp`    | 吃到未核验假饭后短暂显示 | 参考 `char_hit_01.webp`；螺旋眼、张嘴、手臂乱挥、踉跄前进，头顶小问号。     |
| `char-whale-burst.webp` | 爆发开始时短暂显示       | 参考 `char_run_01.webp`；前倾举拳冲刺、星星眼、夸张笑容、头发和鲸尾后扬。   |

均要求单角色全身、透明背景、无文字。运行图用 FFmpeg 依透明区域裁切，缩至 320×320，
脚底与原始跑步帧对齐。素材状态 `generated-pending-review`，并非 DeepSeek 官方形象。
